本仓库是 DeerFlow 的顶层聚合：
- `Makefile` 通过 `scripts/serve.sh`、`scripts/docker.sh`、`scripts/deploy.sh` 把后端（backend_gateway）、前端（frontend_app）和 Docker 编排（docker_infra）统一拉起或关停，并暴露 `dev/start/up/down` 等跨子模块命令。
- `config.example.yaml` 作为运行时配置权威源，被 gateway 与 harness 共享解析，集中声明 models/tools/sandbox/tool_output/safety_finish_reason 等横切能力；`extensions_config.example.json` 则按 MCP 协议扩展工具与服务。
- `skills_catalog` 以 SKILL.md 契约形式向 harness 注册领域技能，由 gateway 在会话中按需加载。
- `docs_and_contracts` 提供跨子模块的设计说明与 JSON 契约，供代码生成与文档站点消费。
- `.pre-commit-config.yaml`、`.env.example`、`.gitignore`、`.dockerignore` 等根级文件对全部子模块施加统一的提交前检查、环境变量模板与构建忽略规则。
