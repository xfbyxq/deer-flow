本模块是纯数据/文档型仓库，不包含可执行代码，所有能力通过 `SKILL.md` 元数据 + 可选 `scripts/`、`references/`、`assets/` 子目录组合而成，由上层 DeerFlow 引擎按 name/description 触发。

- 目录分层：
  - `skills/custom/`：面向金融/投研/工程生产的私有技能（约 100+ 个），每个子目录即一个 skill，如 `strategy-generate`、`tushare`、`okx-market`、`docx`、`pptx`、`xlsx`、`pdf`、`chart-visualization`、`skill-creator` 等。
  - `skills/public/`：开源公共技能，结构相同但更通用，如 `bootstrap`、`deep-research`、`github-deep-research`、`systematic-literature-review`、`vercel-deploy-claimable` 等。
- 文件约定：每个 skill 根目录必须包含 `SKILL.md`（YAML frontmatter 定义 name/description/category）；复杂 skill 再附带 `scripts/`（可执行 Python/JS/sh）、`references/`（按需加载的参考文档）、`assets/`（模板/图标等输出资源）。
- 典型复合 skill 模式：
  - 策略类（`strategy-generate`、`candlestick`、`multi-factor` 等）：`SKILL.md` 描述 SignalEngine 合约与 config.json 格式，`example_signal_engine.py` 给出最小实现，部分带 `references/` 存放理论说明。
  - 数据源类（`tushare`、`yfinance`、`ccxt`、`akshare`、`okx-market`）：`SKILL.md` 列出 API 清单，`scripts/` 提供调用示例。
  - 文档处理类（`docx`、`pptx`、`xlsx`、`pdf`、`xmind`）：除 SKILL.md 外还内嵌 OpenXML XSD schema 和解析脚本，形成自包含的 Office 套件。
  - 工具链类（`skill-creator`、`find-skills`、`claude-to-deerflow`）：内含完整的 eval 循环、benchmark 聚合器、HTML 评测查看器等辅助脚本。
- 依赖方向：SKILL.md 仅作为“指令文档”，不 import 同级 scripts；实际执行由 DeerFlow 引擎在运行时调用 `bash()` / `write_file()` 等工具完成，因此本模块对上层无运行时耦合。
