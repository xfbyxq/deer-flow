- 每个 skill 以独立子目录组织，根目录强制包含 `SKILL.md`，并通过 YAML frontmatter 声明 name/description/category 三元组。
- 大型 skill 采用三层渐进式加载：SKILL.md 正文控制在 ~500 行以内，将详细规范拆入 `references/`，将可执行逻辑放入 `scripts/`。
- 需要运行示例的 skill 统一放置 `example_signal_engine.py` 或 `*_example.py`，并在 SKILL.md 中引用其路径。
- OpenXML 相关 skill（docx/pptx）将官方 XSD schema 原样拷贝到 `openxml/schemas/` 下，并配套 `scripts/validation/` 校验脚本，保持规范与工具同目录。
- 对外部 API 的封装优先使用 `scripts/` 下的 Python 小脚本，并通过环境变量注入密钥（如 QVERIS_API_KEY），避免硬编码。
