- 中间件统一继承 `starlette.middleware.base.BaseHTTPMiddleware` 并重写 `dispatch(self, request, call_next)`，在 `call_next` 前后分别处理请求前置校验与响应后操作。
- 鉴权失败一律返回 `JSONResponse(status_code=401/403, content={"detail": ...})`，并通过 `AuthErrorResponse`/`AuthErrorCode` 枚举结构化错误码而非裸字符串。
- 对不可信外部输入（如 `thread_id`、`assistant_id`、`model_name`、`recursion_limit`）在进入持久化或调度前显式进行白名单/正则/范围钳制，并将越界值记录到 logger 后再降级为默认值。
- 需要跨 handler 传递的身份信息同时写入 `request.state.*` 与 `deerflow.runtime.user_context` ContextVar，并在 `finally` 中用 `reset_current_user(token)` 清理，避免异步任务泄漏上下文。
- 内部可信调用通过固定 header（`X-DeerFlow-Internal-Token`、`X-DeerFlow-Owner-User-Id`）携带，接收端先验证 token 再读取 owner id，并使用 `make_safe_user_id` 规范化后再用于文件系统路径拼接。
- 测试友好：装饰器在检测到 `request` 缺失且函数签名含 `request` 参数时，自动注入带 `_deerflow_test_bypass_auth=True` 的 `SimpleNamespace` 桩对象，跳过真实鉴权以便单元测试直接调用路由处理器。
