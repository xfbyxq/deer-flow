模块按职责拆分为四个子域，全部以纯函数/类形式暴露，由上层 router 或 ASGI 栈装配：
- 认证入口：`auth_middleware.AuthMiddleware`（继承 `BaseHTTPMiddleware`）作为全局 fail-closed 门控，按 `_PUBLIC_PATH_PREFIXES` + `_PUBLIC_EXACT_PATHS` 白名单放行非公开路径；对私有路径依次尝试内部 token（`X-DeerFlow-Internal-Token`）、Cookie JWT（`get_current_user_from_request`）、`DEER_FLOW_AUTH_DISABLED=1` 匿名模式，失败则返回 401；成功时同时写入 `request.state.user`、`request.state.auth_source` 和 `deerflow.runtime.user_context` ContextVar，供下游仓库层 owner 过滤使用。
- 授权装饰器：`authz.py` 定义 `Permissions` 常量、`AuthContext` 以及 `@require_auth` / `@require_permission(resource, action, owner_check, require_existing)` 两个装饰器链，通过 `ThreadMetaStore.check_access` 做线程级所有权校验，并支持内部调用者通过 `X-DeerFlow-Owner-User-Id` 头以连接拥有者身份访问。
- 信任通道与兼容层：`internal_auth.py` 管理进程内共享的内部 token（环境变量或随机生成）及合成用户；`langgraph_auth.py` 复用同一套 JWT/CSRF 逻辑实现 LangGraph SDK 的 `Auth.authenticate`/`Auth.on` 钩子，使 Studio/LangGraph Server 直连场景与 Gateway 行为一致。
- CSRF 防护：`csrf_middleware.CSRFMiddleware` 对 POST/PUT/DELETE/PATCH 执行 Double Submit Cookie 校验，并对 `/api/v1/auth/*` 首登端点额外检查 Origin 是否匹配 `GATEWAY_CORS_ORIGINS` 或同站，同时设置与 `access_token` 同寿命的 `csrf_token` cookie。
- 辅助能力：`trace_middleware.TraceMiddleware` 在请求上下文中注入 `TRACE_ID_HEADER` 并在响应头回写；`services.py` 集中 run 生命周期业务（SSE 帧格式化、输入归一化、run config 构建、recursion_limit 钳制、checkpoint 校验、sse_consumer/wait_for_run_completion），router 仅薄封装；`pagination.py`、`path_utils.py`、`utils.py` 提供分页裁剪、虚拟路径解析与日志参数清洗等通用工具。
依赖方向：本模块向上被 router 与 ASGI 栈消费，向下仅依赖 `app.gateway.deps`、`app.gateway.auth.*`、`deerflow.runtime`、`deerflow.config` 等核心运行时，不反向引用 router。
