- 对外暴露的决策函数统一返回 `(bool, str_reason)` 元组，reason 字符串直接用于结构化日志（如 `action=opened`、`mention required for @bot`）。
- 所有 I/O 密集或可能阻塞的操作（YAML 解析、磁盘 stat、HTTP 请求）都通过 `asyncio.to_thread` 或异步锁保护，确保 webhook 10s 超时不被突破。
- 进程内缓存采用「签名 + 全局 lock」模式：先计算不可变签名（mtime 三元组），命中则直接返回引用，未命中则在 lock 内重建并替换全局变量。
- 对第三方 API 的访问封装为可注入 `client` 参数的函数（如 `mint_installation_token(client=...)`），以便测试时传入 mock httpx.AsyncClient。
- 模块级注册通过「import 即注册」的副作用完成（`run_policy.py` 末尾调用 `register_policy()`），由包级 `__init__.py` 显式 import 保证首次 delivery 前生效。
