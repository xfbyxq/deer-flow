本模块是 DeerFlow 的 HTTP 入口，采用「应用装配 + 中间件 + 路由」三层拼装：
- `app.py`（app_wiring）负责创建 FastAPI 实例、注册 CORS/CSRF/追踪等横切中间件、启动/关闭 LangGraph 运行时单例，并集中 include_router 挂载 routers 下的各业务路由。
- `auth/` 提供可插拔的身份 Provider（JWT / 本地密码 / OIDC-PKCE）与 UserRepository 抽象，被 `auth_middleware`、`internal_auth`、`langgraph_auth` 以及所有需要鉴权的路由复用；`authz.py` 暴露基于资源的权限装饰器供路由层声明式校验。
- `github/` 作为独立事件通道，接收 GitHub App webhook，经 dispatcher 过滤去重后通过 ChannelManager 投递到 Agent 执行，与 REST 路由共享同一套身份上下文。
- `routers/` 按 agents/channels/runs/memory/skills 等业务域拆分，统一依赖 deps.py 提供的请求级依赖注入器获取 Service、Repository 与配置。
- 子模块间不直接 import 彼此内部实现，而是通过 app_wiring 在启动期把 auth providers、repositories、services 等组件装配进 FastAPI 的依赖图，形成单向依赖：routers → middleware/auth → providers/repositories。
