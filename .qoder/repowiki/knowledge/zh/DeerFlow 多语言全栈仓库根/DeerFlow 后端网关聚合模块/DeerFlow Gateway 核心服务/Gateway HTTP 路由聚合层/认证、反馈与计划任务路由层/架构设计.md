四个独立文件各自定义一个 `fastapi.APIRouter` 并通过不同 prefix/tags 挂载到网关：
- `auth.py`：`/api/v1/auth`，集中处理本地邮箱密码登录、注册、改密、初始化管理员、`/setup-status` 缓存、OIDC 授权码+PKCE 流程（state/nonce/PKCE cookie + CSRF double-submit），依赖 `app.gateway.auth.*`、`app.gateway.csrf_middleware`、`deerflow.config.auth_config`；内置每 IP 的进程内失败计数与锁表（多 worker 下不共享）。
- `feedback.py`：`/api/threads/{thread_id}/runs/{run_id}/feedback`，通过 `app.gateway.deps` 注入 `get_feedback_repo` / `get_run_store`，由 `@require_permission("threads", …)` 做资源级权限校验。
- `scheduled_tasks.py`：`/api/scheduled-tasks`，CRUD + pause/resume/trigger/runs 列表，复用 `deerflow.scheduler.schedules.normalize_cron_expression` / `compute_next_run_at` 校验 cron 表达式并计算下次执行时间，同样经 `@require_permission("threads", …)` 鉴权。
- `assistants_compat.py`：`/api/assistants`，仅实现 LangGraph Platform 兼容的最小 stub（search/get/graph/schemas），从 `deerflow.config.agents_config.list_custom_agents()` 读取自定义 agent 配置。

依赖方向单向向外：路由层 → `app.gateway.deps`（依赖注入）、`app.gateway.authz.require_permission`（RBAC）、各业务 repo/service；不直接持有持久化或调度器实例。
