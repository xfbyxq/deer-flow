- 每个资源域独立一个文件，模块顶部声明 `router = APIRouter(prefix="/api", tags=[...])`，并以 `@router.<method>(path, response_model=..., summary=..., description=...)` 装饰器注册端点。
- 请求体与响应体一律使用 Pydantic `BaseModel` + `Field(..., description=...)` 描述，并在函数签名中通过 `response_model=` 强制序列化输出结构。
- 需要鉴权的端点统一叠加 `@require_permission("<resource>", "<action>", owner_check=True, require_existing=True)` 装饰器，将 RBAC 与所有权检查下沉到装饰器而非手写逻辑。
- 外部 I/O（文件系统、数据库、checkpointer）通过 `app.gateway.deps` 中的 `get_*` 工厂在运行时解析，避免在路由层硬编码具体后端实现。
- 对 LangChain/LangGraph 消息对象的字段访问采用 `_message_id/_message_type/_message_content` 等辅助函数统一处理 dict 与 BaseMessage 两种形态，防止客户端传入裸 JSON 导致 AttributeError。
- 阻塞式磁盘操作（如 agent 目录创建/删除、分支沙箱拷贝）封装为同步函数并通过 `asyncio.to_thread` 或 `run_file_io` 调度，确保 FastAPI 事件循环不被阻塞。
