- 每个路由文件独立创建 `APIRouter(prefix=..., tags=[...])` 并通过 `Depends(get_config)` 注入 `AppConfig`，保持配置热重载边界清晰。
- 对外响应体一律用 Pydantic `BaseModel` + `Field(..., description=...)` 声明，并在 `@router.get/post/put/delete` 上标注 `response_model`、`summary`、`description`。
- 需要管理员权限的写操作在 handler 开头显式调用 `await require_admin_user(request, detail=...)`，而非依赖全局中间件。
- 涉及 I/O 或阻塞操作的写路径（如清空系统提示缓存）通过 `asyncio.to_thread` 调度到线程池，避免阻塞事件循环。
- 异常处理采用「先 `except HTTPException: raise` 透传，再 `except Exception` 捕获后 `logger.error(..., exc_info=True)` 并包装为 500」的统一模式。
