- 每个路由文件以 `router = APIRouter(prefix=..., tags=[...])` 自包含地声明路由前缀与标签，再在顶层聚合时 mount。
- 需要鉴权的端点统一使用 `@require_permission(resource, action, owner_check=..., require_existing=...)` 装饰器，而非手动解析用户。
- 请求体与响应体均用 Pydantic BaseModel 显式建模，并在字段上标注 `Field(..., min_length=...)` 等约束。
- 错误返回统一走 `HTTPException(status_code=..., detail=AuthErrorResponse(code=..., message=...).model_dump())` 结构，避免裸字符串。
- 对第三方服务调用（OIDC discovery、agent 配置加载）采用 try/except 捕获后降级为 404/502 或空结果，保证 Gateway 健壮性。
