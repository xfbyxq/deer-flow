本模块由六个独立的 FastAPI `APIRouter` 文件组成，每个文件定义一个资源域的路由集合并通过 `prefix="/api"` + `tags=[...]` 暴露：
- `agents.py`：自定义 Agent 的 CRUD 与用户档案 USER.md 管理，所有端点通过 `_require_agents_api_enabled()` 做功能开关门控，并借助 `deerflow.config.agents_config` 读写文件系统下的 `config.yaml`/`SOUL.md`；阻塞式 IO 通过 `asyncio.to_thread` 移出事件循环。
- `models.py`：只读地枚举 `AppConfig.models`，供前端选择可用 LLM 模型。
- `threads.py`：线程生命周期（创建/搜索/删除/分支/目标设置）与状态快照，底层依赖 LangGraph Checkpointer 持久化 checkpoint，并通过 `ThreadMetaStore` 维护元数据；分支操作会按策略复制沙箱用户数据。
- `thread_runs.py`：线程级 Run 管理（创建、SSE 流式、等待、取消、加入、消息/事件/工作区变更查询、token 用量聚合），实现 LangGraph Platform runs API 协议，SSE 格式对齐 `useStream` React hook。
- `runs.py`：无状态 run 入口（自动创建临时 thread），复用 `thread_runs` 中的 `RunCreateRequest` 与服务层 `start_run`/`sse_consumer`。
- `memory.py`：全局记忆数据的 CRUD、导入导出与配置查看，受 `get_memory_config().enabled` 控制，内部通过 `deerflow.agents.memory.updater` 访问持久化存储。

依赖方向：路由层仅依赖 `app.gateway.deps`（`get_checkpointer`、`get_run_manager`、`get_stream_bridge`、`get_thread_store` 等）和 `deerflow.*` 领域服务，不直接持有业务对象；权限校验统一走 `app.gateway.authz.require_permission` 装饰器，用户身份从 `get_effective_user_id()` / `get_current_user(request)` 注入。
