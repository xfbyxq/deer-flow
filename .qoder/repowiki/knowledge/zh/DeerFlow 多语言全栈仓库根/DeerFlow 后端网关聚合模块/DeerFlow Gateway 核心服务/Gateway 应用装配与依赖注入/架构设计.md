本模块是 DeerFlow API Gateway 的进程入口与装配层，由三个文件构成清晰的职责分层：
- `config.py`：定义仅从环境变量加载的轻量 `GatewayConfig`（host/port/docs），通过全局 `_gateway_config` 缓存避免重复解析。
- `deps.py`：集中管理所有跨请求的单例生命周期。`langgraph_runtime` 作为 `AsyncExitStack` 上下文管理器在 lifespan 内初始化 StreamBridge、SQLAlchemy Engine、Checkpointer、Store、RunEventStore、ThreadMetaStore、RunManager 等，并将它们挂到 `app.state`；同时提供 `_require` 工厂批量生成 `get_stream_bridge` / `get_run_manager` / `get_checkpointer` / `get_run_event_store` / `get_feedback_repo` / `get_run_store` 等 FastAPI 依赖函数，缺失时统一返回 503。`get_config()` 走 `deerflow.config.app_config.get_app_config` 实现 mtime 热重载，与引擎层的“启动快照”形成明确的 hot-reload boundary。`get_local_provider` 懒缓存 LocalAuthProvider + SQLiteUserRepository，供认证路径使用。
- `app.py`：`create_app()` 构造 FastAPI，按固定顺序挂载 AuthMiddleware → CSRFMiddleware → CORSMiddleware → TraceMiddleware，再逐一 `include_router` 注册各业务路由；`lifespan` 负责启动阶段：加载配置并 `configure_logging`、预热 tiktoken 编码缓存、清理过期上传临时文件、进入 `langgraph_runtime`、执行首次启动的 admin 引导与孤儿线程迁移、按需启动 IM channel service 与定时任务服务；shutdown 阶段则按相反顺序优雅关闭 OIDC、channel service、scheduled task service，并对每个钩子施加 5s 超时防止 uvicorn 重启风暴卡住 worker。

依赖方向单向：`app.py` 依赖 `deps.py` 和 `config.py`，`deps.py` 不反向导入 `app.py`，通过 `request.app.state` 间接访问已初始化的单例，从而避免循环导入。
