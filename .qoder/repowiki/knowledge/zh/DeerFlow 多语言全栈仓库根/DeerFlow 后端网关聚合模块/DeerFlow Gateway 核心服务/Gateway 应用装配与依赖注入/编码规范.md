- 对可能缺失的全局单例统一用 `_require(attr, label)` 工厂生成 FastAPI 依赖，缺失时返回 503，避免在每个路由中重复写 getattr + HTTPException。
- 启动期一次性快照的 AppConfig 传入 `langgraph_runtime` 构建引擎，而请求期通过 `get_config()` 重新读取 `config.yaml`，以注释明确区分 restart-required 与 hot-reloadable 字段边界。
- 所有外部资源（engine、checkpointer、store、channel service、scheduled task service）都在 `AsyncExitStack` 或显式 try/except 包裹的 shutdown 分支中关闭，并为每个关闭操作设置 5s 超时防止 worker 卡死。
- 可选功能（GitHub webhooks、docs、IM channels、scheduled tasks）通过 `is_route_enabled()` 或配置开关条件挂载，未启用时返回 404 而非空处理器，遵循 fail-closed 原则。
