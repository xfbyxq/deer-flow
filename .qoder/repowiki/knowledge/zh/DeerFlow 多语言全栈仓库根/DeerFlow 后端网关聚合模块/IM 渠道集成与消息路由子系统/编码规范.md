- 新增渠道需在 `service._CHANNEL_REGISTRY` 中以字符串 import 路径注册，并在 `manager.CHANNEL_CAPABILITIES` 声明 `supports_streaming` 能力，而非在代码中硬编码分支。
- 渠道适配器的启动/停止由 `ChannelService._start_channel` 统一通过反射 `resolve_class(import_path)` 实例化，子类仅实现 `start/stop/send` 生命周期方法，不直接参与服务发现。
- 对外部不可信输入（artifact 路径、文件名、assistant_id）一律做前缀白名单或正则校验后再落盘，失败时记录 warning 并跳过而非抛错中断流程。
- 对第三方 HTTP 调用封装在 `Channel._send_with_retry` 指数退避重试中，日志统一带 `[<channel_name>]` 前缀，便于跨渠道追踪。
- 运行时配置通过 `ChannelService.from_app_config` 合并 `config.yaml` 与 UI 运行时 overlay，并以 `asyncio.to_thread` 把磁盘 IO 移出事件循环。
