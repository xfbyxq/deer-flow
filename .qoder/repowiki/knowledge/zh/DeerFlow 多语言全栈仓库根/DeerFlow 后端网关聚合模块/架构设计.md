本模块是 `backend/app` 的入口聚合层，由 `gateway/app.py::create_app()` 统一装配：
- 中间件链（Auth → CSRF → CORS → Trace）包裹所有路由，构成跨子系统的横切面。
- `lifespan` 钩子在启动时依次加载配置、预热 tiktoken、初始化 `langgraph_runtime`（注入 `app.state.store`/checkpointer 等）、按需拉起 `channels.service.start_channel_service` 与 `scheduler.ScheduledTaskService`；关闭时按相反顺序释放资源并带超时保护。
- 路由通过 `routers/__init__.py` 集中 `include_router`，按业务域拆分（agents、artifacts、auth、channels、console、github_webhooks、mcp、memory、models、runs、scheduled_tasks、skills、suggestions、thread_runs、threads、uploads），其中 GitHub Webhook 路由仅在配置了 secret 或显式允许时才挂载，作为 fail-closed 的安全策略。
- `channels` 与 `gateway.github` 共享 ChannelRunPolicy 注册机制：后者通过导入副作用向 ChannelManager 注册 GitHub 专属运行策略，使 IM 入站消息能触发 Agent 执行。
- 依赖注入集中在 `gateway/deps.py`，各 router 通过 FastAPI Depends 获取 LangGraph runtime、存储、用户上下文等共享组件，避免直接耦合。
