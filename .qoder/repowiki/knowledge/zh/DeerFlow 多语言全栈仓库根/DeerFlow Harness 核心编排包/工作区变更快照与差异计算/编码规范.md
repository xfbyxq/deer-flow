- 所有领域模型使用 `@dataclass(frozen=True)` 构造不可变值对象，并通过 `to_dict()` 方法序列化供事件存储使用。
- 可配置上限集中封装在 `WorkspaceChangeLimits` dataclass 中，各函数以 `limits: WorkspaceChangeLimits | None = None` 参数传入并在内部 `resolved_limits = limits or WorkspaceChangeLimits()` 合并默认值。
- 内容不可用的原因统一使用 `DiffUnavailableReason` Literal（binary/large/sensitive/truncated）作为标记字段，而非抛出异常。
- 对外暴露的入口函数采用 keyword-only 参数风格（如 `*, include_files: bool = True`），保持 API 向后兼容。
- 需要 I/O 的阻塞操作通过 `asyncio.to_thread` 包装后在异步上下文中调用，避免阻塞事件循环。
