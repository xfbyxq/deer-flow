- Provider 以 Protocol + `@runtime_checkable` 形式声明契约，不强制继承基类，通过 `resolve_variable()` 按字符串类路径动态加载。
- 所有 Provider 必须同时实现同步 `evaluate` 与异步 `aevaluate`，允许后者委托前者（如 AllowlistProvider）。
- 决策返回统一使用 `GuardrailDecision(allow=..., reasons=[GuardrailReason(code=..., message=...)])`，拒绝原因 code 采用 `oap.*` 前缀命名空间。
- 中间件对可选的外部依赖（如 `__run_journal`）采用 best-effort try/except 包裹，确保 guardrail 失败不会中断主流程。
