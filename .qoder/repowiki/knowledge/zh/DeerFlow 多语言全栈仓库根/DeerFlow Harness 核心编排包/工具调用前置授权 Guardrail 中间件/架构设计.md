模块围绕一个纯 Protocol 契约与 LangGraph `AgentMiddleware` 适配器展开：
- `provider.py` 定义不可变数据类 `GuardrailRequest`/`GuardrailReason`/`GuardrailDecision`（对齐 OAP 的 Decision/Reason 对象）以及 `@runtime_checkable` 的 `GuardrailProvider` Protocol，要求实现同步 `evaluate` 与异步 `aevaluate`，并通过 `name` 字段暴露标识；文档指出 Provider 由 DeerFlow 统一的 `resolve_variable()` 按类路径加载，与模型/工具/sandbox 的加载机制一致。
- `middleware.py` 中的 `GuardrailMiddleware(AgentMiddleware[AgentState])` 是实际拦截点，覆写 `wrap_tool_call` / `awrap_tool_call`，从 `ToolCallRequest.runtime.context` 提取 thread/user/oauth 等上下文填充 `GuardrailRequest`，调用 Provider 后根据 `fail_closed` 决定 provider 异常时 deny 还是 warn-through，并将结果写入可选的 `__run_journal`（通过 `journal.record_middleware(tag="guardrail", hook="wrap_tool_call")`），无 Journal 的环境直接跳过持久化。
- `builtin.py` 提供零依赖的 `AllowlistProvider`，支持白名单 + 黑名单组合，作为默认 Provider 示例。
- `__init__.py` 仅做 re-export，对外暴露 Provider 协议、内置实现与中间件三类符号。
依赖方向单向：middleware → provider 协议 → builtin 实现，外部 Provider 只需实现 Protocol 即可接入，无需继承基类。
