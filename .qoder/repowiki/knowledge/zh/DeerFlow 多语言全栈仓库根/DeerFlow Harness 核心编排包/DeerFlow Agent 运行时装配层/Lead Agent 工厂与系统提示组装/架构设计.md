模块由三个文件组成，职责清晰分层：
- `agent.py`：唯一对外入口 `make_lead_agent(config)`（兼容 LangGraph Server 签名），内部 `_make_lead_agent` 完成模型名解析、tracing callback 挂载、工具策略过滤、deferred tool 装配，并按 `is_bootstrap` 分支返回不同的 agent；`build_middlewares` 是公共中间件组装器，被 `make_lead_agent` 和嵌入式 `DeerFlowClient` 共同复用。
- `prompt.py`：纯函数式提示模板拼装层，提供 `apply_prompt_template`、`get_skills_prompt_section`、`get_enabled_skills_for_config` 等，通过 LRU + 后台线程缓存已启用技能列表，避免请求路径阻塞磁盘 I/O。
- `__init__.py`：仅暴露 `make_lead_agent`，隐藏内部构造细节。

依赖方向单向向外：本模块依赖 `deerflow.tools`、`deerflow.skills`、`deerflow.config`、`deerflow.tracing`、`deerflow.agents.middlewares.*`、`deerflow.models`，不被同级其他 agents 反向引用。关键不变量在模块顶部注释中声明：所有图内 `create_chat_model` 必须传 `attach_tracing=False`，tracing 仅在根节点挂一次以避免重复 span 和 session_id 丢失。
