- 对外暴露的存储/队列/模型实例均通过模块级 `_xxx_instance` + `get_xxx()` 双检锁单例模式获取，避免重复初始化。
- LLM 返回的 JSON 一律先经 `_parse_*_response` 再走 `_normalize_*` 归一化函数，对字段类型、置信度范围、空值做严格校验后再写入。
- 异步入口 (`aupdate_memory`) 始终委托给同步 `_do_update_memory_sync`，通过 `asyncio.to_thread` 或 `concurrent.futures.ThreadPoolExecutor` 运行，禁止在 memory 路径创建新事件循环。
- 跨线程边界（Timer、executor）传递的 `deerflow_trace_id` 在进入处理逻辑前用 `request_trace_context(id)` 显式 rebind，确保日志与 tracing 关联正确。
- 面向用户的字符串模板集中在 `prompt.py` 中以常量字符串形式管理，运行时仅通过 `.format(...)` 注入变量，不在业务代码里拼接 prompt。
