- 所有中间件均继承 `langchain.agents.middleware.AgentMiddleware[AgentState]` 并在同步与异步钩子上成对实现 (`before_agent`/`abefore_agent`、`wrap_model_call`/`awrap_model_call`)。
- 框架注入的数据一律放入 `additional_kwargs={'hide_from_ui': True, <专属键>: True}` 的隐藏消息，并由同名 `is_xxx_reminder(message)` 辅助函数识别，避免与用户输入混淆。
- 对任意来自消息流的字符串进行渲染前先经 `html.escape(..., quote=False)` 处理，防止不可信内容获得系统角色权限。
- 长文本输出统一采用 head/tail 截断配合 `\n...\n` 省略标记，并以模块级常量定义字符预算（如 `_SUMMARY_RENDER_CHAR_BUDGET`、`_LEDGER_RENDER_CHAR_BUDGET`）。
- 需要 I/O 的同步操作（文件读取、tiktoken 初始化）通过 `asyncio.to_thread` 包裹，并用 `asyncio.wait_for(timeout=...)` 限制最大耗时以防事件循环饥饿。
