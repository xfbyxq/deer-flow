本目录是 DeerFlow Agent 的横切能力装配层，所有子模块均实现 LangChain 的 `AgentMiddleware` 接口，通过 `before_model` / `after_model` / `before_llm_call` / `after_llm_call` 钩子在 LLM 调用链路中串联执行。
- 安全与循环检测（safety_termination）位于链尾，拦截 after_model 输出以抑制截断 tool_calls 并强制打断重复调用。
- 工具调用处理（tool_call_handling）在 after_model 阶段消费/修复 tool_calls，并通过 tool_output_budget_middleware 限制单次输出 token。
- 上下文与技能（context_thread_management + uploads_viewing）在 before_model 前注入系统提示、上传文件元数据、动态记忆与斜杠技能绑定。
- 运行期预算（token_output_budgeting）按 run 累计 token 用量并在达到阈值时触发 safety_termination 的终止信号。
- 对话流（conversation_flow）在消息进入/离开时维护澄清状态、标题、待办与摘要压缩。
- 各中间件通过共享的 `delegation_ledger.py`、`skill_context.py`、`tool_call_metadata.py` 等模块交换运行时状态，形成从输入清洗 → 上下文注入 → 工具执行 → 安全校验 → 摘要归档的单向流水线。
