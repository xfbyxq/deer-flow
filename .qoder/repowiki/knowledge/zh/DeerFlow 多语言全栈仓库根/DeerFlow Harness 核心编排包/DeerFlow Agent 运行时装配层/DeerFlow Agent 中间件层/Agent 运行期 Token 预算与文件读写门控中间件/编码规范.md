- 每个中间件同时实现同步与异步双写方法（`before_agent`/`abefore_agent`、`after_model`/`aafter_model`、`wrap_model_call`/`awrap_model_call`），后者直接委托前者或经 `asyncio.to_thread` 包装。
- 运行时隔离键统一从 `runtime.context` 字典中提取（run_id/thread_id/sandbox_id），并在缺失时回退到 `id(runtime)` 或 "global"，避免跨进程/沙箱状态串扰。
- 易膨胀的 per-run 缓存一律用自定义 `BoundedDict(OrderedDict)` 包裹并以固定 maxsize=1000 做 LRU 淘汰，配合 `reset()` 与 `after_agent` 清理，防止 abandoned run 泄漏。
- 对外暴露的 `from_config` 类方法与 `__init__(config)` 成对出现，由上层配置工厂统一构造中间件实例。
- 可失败的外部 I/O（沙箱读文件）采用 fail-open 策略：捕获异常或识别 `Error:` 前缀的错误字符串后记录日志并放行，让工具自身返回错误而非中间件阻断。
