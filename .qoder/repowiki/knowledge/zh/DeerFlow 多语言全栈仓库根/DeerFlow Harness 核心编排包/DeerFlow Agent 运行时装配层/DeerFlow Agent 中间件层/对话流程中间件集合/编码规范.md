- 每个中间件都定义一个继承自 `AgentState` 的 `*MiddlewareState` 内部类作为 `state_schema`，并在 async/sync 方法上成对实现 `a*` 版本。
- 对外部可配置项采用三层降级：实例参数 → 传入的 app_config → 模块级 `get_*_config()` 默认值，便于测试注入与运行时覆盖。
- 需要跳过前端流式输出的 LLM 调用统一通过 `with_config(tags=[..., TAG_NOSTREAM])` 创建副本模型，而不是替换实例上的 `self.model`，以避免并发泄漏。
- 对可能来自不同 provider/LangChain 版本的字段访问一律走 helper 函数（如 `_has_tool_call_intent_or_error`、`is_dynamic_context_reminder`），并在注释中注明升级时需同步更新对应测试。
- 向消息列表注入的内部提示统一使用 `HumanMessage(..., name="...", additional_kwargs={"hide_from_ui": True})` 形式，确保不会泄露到用户可见界面。
