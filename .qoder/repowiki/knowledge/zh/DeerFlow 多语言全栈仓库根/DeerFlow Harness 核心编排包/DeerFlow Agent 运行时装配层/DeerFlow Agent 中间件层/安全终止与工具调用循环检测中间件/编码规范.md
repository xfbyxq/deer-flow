- 所有 detector 实现遵循 `SafetyTerminationDetector` Protocol，暴露 `name: str` 属性与纯函数式 `detect(message) -> SafetyTermination | None`，且对缺失/异常 metadata 保持容错（try/except + logger.exception）。
- 配置型中间件提供 `from_config(cls, config)` 类方法，通过 `deerflow.reflection.resolve_variable(entry.use)` 动态加载探测器类，并在空列表时显式抛出 ValueError 而非静默禁用。
- 对 provider 返回的 finish/stop reason 统一通过 `_get_metadata_value` 从 `response_metadata` 和 `additional_kwargs` 两个容器按序查找，仅接受字符串值，避免 Pydantic enum/dict 导致异常。
- 向 AIMessage 内容追加文本时使用统一的 `_append_text` / `_append_user_message` 模式：None→替换、list→追加 `{"type": "text", ...}` block、str→拼接，防止对 Anthropic thinking blocks 等 list-content 触发 TypeError。
- 可观测性输出采用双通道：实时通过 `get_stream_writer()` 发送 SSE 事件（失败仅 debug 日志），持久化通过 runtime.context['__run_journal'].record_middleware(tag=...) 写入 RunEventStore，且刻意省略被过滤的工具参数。
- 中间件内部可变状态使用 `threading.Lock` 保护，并以 `(thread_id, run_id)` 作为 key 做 LRU 淘汰，`reset(thread_id=None)` 暴露按线程或全局清理入口。
