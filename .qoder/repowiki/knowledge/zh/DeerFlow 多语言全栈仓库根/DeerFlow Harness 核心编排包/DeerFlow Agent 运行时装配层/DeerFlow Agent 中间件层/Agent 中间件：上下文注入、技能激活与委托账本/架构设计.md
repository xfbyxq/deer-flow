本模块以一组独立的 `langchain.agents.middleware.AgentMiddleware` 子类为核心，各自在 agent 执行生命周期的不同钩子点工作，通过读写 `AgentState` 字段协作：
- `DynamicContextMiddleware.before_agent`：首次对话或跨午夜时向消息序列插入 `<system-reminder>` SystemMessage（框架数据）与可选的 HumanMessage（用户记忆），使用 ID-swap 技术保持首条消息冻结以复用前缀缓存。
- `DurableContextMiddleware.wrap_model_call`：在每次模型调用前从 `state['messages']` 提取已加载技能与任务委托，渲染为隐藏的 `<durable_context_data>` HumanMessage；`after_model` 阶段增量更新 `delegations` / `skill_context` 状态字段。
- `SkillActivationMiddleware.wrap_model_call`：扫描最后一条人类消息中的 `/skill-name` 斜杠引用，解析并读取 SKILL.md，将其完整内容作为隐藏 HumanMessage 插入目标位置，同时基于 `ThreadState.skill_context` 与运行时 `context.secrets` 计算每调用的密钥注入集，写入 `ACTIVE_SECRETS_CONTEXT_KEY` 并审计到 `__run_journal`。
- `ThreadDataMiddleware.before_agent`：按 thread_id + user_id 创建 sandbox 目录结构，并将路径写入 `thread_data` 状态字段。
- `MemoryMiddleware.after_agent`：过滤出人类输入与最终 AI 回复，检测纠正/强化信号后入队异步记忆更新。
- 纯函数工具包 `delegation_ledger.py`、`skill_context.py` 负责从消息流中确定性地抽取委托与技能条目并渲染为带预算截断的文本块，被上述中间件复用。
依赖方向单向：中间件 → 工具函数 → `deerflow.agents.thread_state` / `deerflow.skills.*` / `deerflow.runtime.secret_context`，中间件之间不直接互相导入，仅通过共享的 state 字段契约通信。
