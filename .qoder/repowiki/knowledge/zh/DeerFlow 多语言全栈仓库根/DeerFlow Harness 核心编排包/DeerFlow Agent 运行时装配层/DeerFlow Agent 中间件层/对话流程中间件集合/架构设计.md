本模块是 DeerFlow 导流代理（lead agent）的中间件层，每个文件实现一个独立的 `AgentMiddleware` 子类，通过覆写 `wrap_tool_call`/`wrap_model_call`/`before_model`/`after_model` 等钩子在工具调用或模型调用前后插入行为。

- 澄清中断 (`clarification_middleware.py`)：拦截 `ask_clarification` 工具调用，返回 `Command(goto=END)` 以同步中断执行并向前端展示问题；当运行上下文设置 `disable_clarification` 时退回为普通 `ToolMessage` 让模型自行推进。
- 系统消息合并 (`system_message_coalescing_middleware.py`)：在 `wrap_model_call` 阶段把 `request.system_message` 与 `messages` 中的多个 `SystemMessage` 合并为单个前导 `SystemMessage`，同时去重动态上下文提醒，避免 vLLM/SGLang/Qwen 等严格后端报错。
- 标题生成 (`title_middleware.py`)：在 `after_model` 中检测首个完整人机轮次后调用 LLM 生成线程标题，失败回退到本地截取用户首条消息；通过 `_get_runnable_config()` 继承父级 `RunnableConfig` 并注入 `middleware:title` 标签以便 RunJournal 区分来源。
- 待办事项 (`todo_middleware.py`)：扩展 `langchain.agents.middleware.TodoListMiddleware`，在 `before_model` 检测 `write_todos` 是否被摘要挤出上下文并注入隐藏提醒；在 `after_model` 中若模型无工具调用意图且存在未完成 todo，则通过 `jump_to="model"` 强制继续循环，并用线程/运行键控的内存队列限制重复提醒次数。
- 摘要压缩 (`summarization_middleware.py`)：扩展 `SummarizationMiddleware`，在 `_create_summary` 中使用带 `TAG_NOSTREAM` 的副本模型避免摘要调用被前端误收为 AI 消息；提供 `BeforeSummarizationHook` Protocol 和 `SummarizationEvent` 数据类，在压缩前触发外部 hook（如日志记录），并通过 ID-swap 前缀匹配保留 DynamicContext 三元组不被压缩进摘要。

依赖方向：中间件之间不直接互相 import，仅通过共享的 `dynamic_context_middleware.is_dynamic_context_reminder` 标记约定以及 `ThreadState`/`AgentState` 结构进行协作；所有中间件均声明 `state_schema = ...` 以兼容 LangGraph 的状态校验。
