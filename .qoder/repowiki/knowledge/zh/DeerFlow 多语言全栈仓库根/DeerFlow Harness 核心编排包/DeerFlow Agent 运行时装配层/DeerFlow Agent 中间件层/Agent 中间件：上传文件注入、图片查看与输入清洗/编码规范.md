- 每个中间件都同时实现同步与异步两个钩子方法（`before_agent` + `abefore_agent`、`before_model` + `abefore_model`、`wrap_model_call` + `awrap_model_call`），后者仅委托前者或调用 `run_in_executor` 避免阻塞事件循环。
- 系统注入的消息一律携带 `additional_kwargs={"hide_from_ui": True}`，并通过 `_is_genuine_user_message` 等辅助函数排除这些消息，确保只处理真实用户输入。
- 对可能被上游中间件修改过的用户文本，使用 `setdefault(ORIGINAL_USER_CONTENT_KEY, ...)` 保存原始内容，保证幂等且不被覆盖。
- 对可能产生阻塞 IO 的操作（目录遍历、stat、读取 .md 大纲）统一通过 `run_in_executor(None, sync_fn, ...)` 派发到线程池执行。
