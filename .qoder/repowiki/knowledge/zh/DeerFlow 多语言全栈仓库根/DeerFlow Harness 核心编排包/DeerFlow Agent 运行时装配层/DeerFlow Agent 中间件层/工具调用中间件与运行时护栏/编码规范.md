- 每个中间件均同时实现 sync 与 async 版本的钩子方法（如 `wrap_model_call`/`awrap_model_call`、`wrap_tool_call`/`awrap_tool_call`、`after_model`/`aafter_model`），保持双轨一致。
- 对可能产生大文本的工具输出采用「持久化到虚拟路径 + 内联预览」策略，预览使用 `_snap_to_line_boundary` 对齐换行，并在提示中标注省略字符数与 token 估算。
- 通过 `@override` 装饰器显式标注 LangChain 钩子重写，配合 `from __future__ import annotations` 与 PEP 604 联合类型声明。
- 中间件间通过 `AgentState` 字段（如 `state['promoted']`、`state['thread_data']['outputs_path']`、`state['sandbox']`）而非全局变量传递上下文，并按 catalog_hash 做作用域隔离。
- 可选功能通过工厂函数（`from_app_config`、`from_config`）或 `build_*_runtime_middlewares` 装配器条件性注册，避免硬编码依赖。
