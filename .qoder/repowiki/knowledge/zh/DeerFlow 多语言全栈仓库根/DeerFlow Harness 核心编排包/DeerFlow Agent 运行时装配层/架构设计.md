本模块是 agents 子系统的装配中心，承担三层职责：
- 顶层入口 `__init__.py` 使用 `__getattr__` 延迟导入 `create_deerflow_agent`、`make_lead_agent`、`ThreadState`，避免轻量子模块被连带拉入重型工具/子代理图。
- `factory.py` 提供 SDK 级 `create_deerflow_agent`，在 `features.py` 的 `RuntimeFeatures` 数据类驱动下，按固定 14 步顺序（sandbox → dangling_tool_call → guardrail → tool_error_handling → summarization → todo → auto_title → memory → vision → subagent_limit → loop_detection → token_budget → clarification）构建中间件链，并通过 `@Next`/`@Prev` 装饰器支持外部中间件以锚点方式插入，同时保证 ClarificationMiddleware 始终位于末尾。
- 该装配器把 lead_agent（系统提示与模型）、middlewares（横切能力）、memory（长期记忆注入）三者解耦：lead_agent 只负责渲染提示并返回 LangGraph 图，memory 通过 MemoryMiddleware 在调用前注入事实，所有中间件共享 ThreadState/SandboxState 作为跨阶段通信契约。
