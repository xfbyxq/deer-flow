本模块是 DeerFlow 的 SDK 级入口，位于 raw langchain.agents.create_agent 与应用层 make_lead_agent 之间，职责单一：把 Python 参数装配成可执行的 CompiledStateGraph。

- factory.py 暴露唯一公共 API `create_deerflow_agent`，内部通过 `_assemble_from_features` 按固定顺序（0–14）构建中间件链：sandbox 基础设施 → DanglingToolCall → Guardrail → ToolErrorHandling → Summarization → TodoMiddleware(plan_mode) → AutoTitle → Memory → Vision → SubagentLimit → LoopDetection → TokenBudget → Clarification（始终最后），并附带注入 view_image_tool / task_tool / ask_clarification_tool 等工具。
- features.py 定义纯数据类 RuntimeFeatures（字段接受 True/False/AgentMiddleware 三态）以及 @Next/@Prev 装饰器，用于在“第二阶段”将用户自定义中间件插入到已排序链中；_insert_extra 实现冲突检测、循环依赖检测与跨外部锚点解析。
- goal_state.py 仅声明 GoalBlocker 字面量与 GoalEvaluation/GoalState TypedDict，作为目标评估的状态契约，被上层 agent 消费。

依赖方向：factory → features/goal_state → 各 middlewares/* 与 tools/builtins（延迟 import 避免循环）；features 与 goal_state 不反向依赖 factory，保持无副作用的数据层。
