模块按职责拆分为若干独立文件：
- `config.py` 定义不可变数据类 `SubagentConfig`（名称、system_prompt、tools/disallowed_tools 白/黑名单、skills、model、max_turns、timeout_seconds），并提供 `resolve_subagent_model_name` 继承策略。
- `builtins/` 包集中声明两个内置 `SubagentConfig`（`general-purpose`、`bash`），并通过 `BUILTIN_SUBAGENTS` 字典暴露给上层。
- `registry.py` 实现三层配置覆盖：先取 builtins，再合并 `config.yaml` 的 `custom_agents`，最后应用 per-agent 覆盖（仅对 builtins 生效全局默认值），并基于 `is_host_bash_allowed` 过滤对外可见的子代理名。
- `executor.py` 是核心：`SubagentExecutor` 通过 LangChain `create_agent` + LangGraph 构建子代理图，使用 `stream_mode="values"` 增量收集 AI 消息；当调用方已存在运行中的事件循环时，通过 `_get_isolated_subagent_loop` 在独立线程中复用持久 asyncio loop，避免每次 `asyncio.run` 关闭共享 async 客户端；`execute_async` 将任务提交到固定大小的 `ThreadPoolExecutor`，并以 `FuturesTimeoutError` 触发 `cancel_event` 做协作式取消；`SubagentResult.try_set_terminal` 用锁保证终态只写一次。
- `step_events.py` 纯函数层，把 LangChain `AIMessage`/`ToolMessage` 转成紧凑 JSON step 并映射 `task_*` 自定义流事件为 `RunEventStore` 的 `subagent.step/start/end` 事件，统一用于实时推送和持久化。
- `status_contract.py` 定义后端→前端的 `additional_kwargs` 契约（`subagent_status`、`subagent_result_brief/sha256`、`subagent_error`），由 `make_subagent_additional_kwargs` / `format_subagent_result_message` 生成，供中间件写入 ToolMessage。
- `token_collector.py` 作为 LangChain `BaseCallbackHandler` 收集子代理 LLM token 用量，按模型分桶后回传父 RunJournal。
依赖方向：`executor` → `config`/`registry`/`step_events`/`token_collector`；`registry` → `builtins` + 外部 `deerflow.sandbox.security`；`__init__.py` 通过 `__getattr__` 延迟导出 `SubagentExecutor`/`SubagentResult` 以避免循环导入。
