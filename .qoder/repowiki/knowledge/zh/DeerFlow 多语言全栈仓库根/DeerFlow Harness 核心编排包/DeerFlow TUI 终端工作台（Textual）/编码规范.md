- 所有可观察 UI 状态集中在 `view_state.py` 中以 frozen dataclass 表示，并通过单一 `reduce(state, action)` 纯函数更新，禁止在 UI 层直接 mutate 状态。
- 对外部 I/O（client/stream、DB、文件系统）一律用 try/except 包裹并以 `# noqa: BLE001` 注释标注 best-effort，确保 UI 不会因下游异常崩溃。
- 需要异步/阻塞调用的操作通过 `run_worker(..., thread=True, exclusive=True, group=...)` 放入 Textual worker 线程，再用 `call_from_thread` 回调到 UI 线程。
- 纯逻辑（状态规约、渲染、命令解析）与框架无关，独立成文件并在 `app.py` 中按需 import，避免 headless 路径加载 Textual/Rich。
- 对外部客户端接口使用 `Protocol`（如 `_ClientLike`、`_StreamEventLike`）而非具体类型，使 `runtime.translate` 可被单元测试 mock。
- 用户输入统一经 `command_registry.resolve` 分类为 builtin/skill/unknown/message，再由 `DeerFlowTUI._handle_builtin` 分派，不在事件处理器里写 if/else 分支。
