模块以 `__init__.py` 作为对外门面，仅暴露三个符号：`build_tracing_callbacks`、`build_langfuse_trace_metadata`、`inject_langfuse_metadata`。

- `factory.py`：工厂层，通过 `deerflow.config.get_enabled_tracing_providers()` 读取配置并动态创建对应 tracer/handler；LangSmith 使用 `langchain_core.tracers.langchain.LangChainTracer`，Langfuse 先初始化全局 `Langfuse` 客户端再返回 `langfuse.langchain.CallbackHandler`，二者均被包装在 `_create_*` 私有函数中以延迟 import 避免循环依赖。
- `metadata.py`：Langfuse 专用元数据构建器，基于 Langfuse v4 的保留键约定（`langfuse_session_id`/`langfuse_user_id`/`langfuse_trace_name`/`langfuse_tags`）生成 `RunnableConfig.metadata`；`inject_langfuse_metadata` 通过 `setdefault` 合并，保证上游传入值优先，且当 Langfuse 未启用时直接返回空字典，使调用方可无条件 merge。
- 依赖方向单向向外：本模块依赖 `deerflow.config`、`deerflow.trace_context`、`deerflow.runtime.user_context`，但被 `runtime/runs/worker.py` 等上层组件反向导入，因此所有第三方库（langchain、langfuse）均采用函数内局部 import 以避免启动期循环导入。
