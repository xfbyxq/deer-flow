本包是 DeerFlow 的顶层装配层，通过 `agents/factory.py` 作为入口，把以下层次串联为一条固定的执行管线：
- 配置层（`config/`）：Pydantic YAML + 环境变量 + 热重载，为所有子模块提供统一的 `AppConfig`。
- 模型层（`models/`）：工厂按配置创建 BaseChatModel 实例，注入 tracing 元数据后交给上层。
- 工具层（`tools/` + `community/` + `mcp/`）：内置工具、社区搜索/抓取工具与 MCP 服务器工具经同一注册表聚合，供 Agent 发现。
- 中间件链（`agents/middlewares/`）：按固定顺序挂载安全、限流、记忆、标题生成、上传、循环检测等横切能力。
- 运行期（`runtime/` + `persistence/`）：以 LangGraph checkpointer/store 为核心，管理 Run 生命周期、SSE 流桥与事件存储；`persistence/` 用 SQLAlchemy 异步 ORM + Alembic 维护线程/任务/连接等状态。
- 扩展域（`sandbox/`、`skills/`、`subagents/`、`guardrails/`、`tracing/`、`tui/`、`workspace_changes/`、`utils/`）：各自实现独立接口，由 factory/runtime 在启动时按需装配。
跨子模块的契约集中在 `agents/thread_state.py`、`agents/goal_state.py`、`runtime/journal.py` 以及各 provider 抽象类上，确保中间件、checkpointer、store、stream_bridge 等组件可被替换而不改动调用方。
