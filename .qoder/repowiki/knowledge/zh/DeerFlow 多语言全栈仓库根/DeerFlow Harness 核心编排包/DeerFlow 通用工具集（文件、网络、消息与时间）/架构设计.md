本模块是纯工具包，按职责拆分为独立文件，彼此无内部依赖，仅被上层 harness 组件导入使用：
- `file_io.py`：通过 `concurrent.futures.ThreadPoolExecutor` 暴露 `run_file_io`，在专用线程池中执行阻塞型文件系统调用，并用 `contextvars.copy_context` 把运行期上下文（如用户 ID）透传到工作线程，进程退出时由 `atexit` 关闭。
- `network.py`：`PortAllocator` 类维护线程安全的已分配端口集合，对外暴露 `get_free_port` / `release_port` 全局函数及 `allocate_context` 上下文管理器；端口可用性检测绑定 `0.0.0.0` 以匹配 Docker 行为。
- `file_conversion.py`：PDF/Office→Markdown 转换入口，支持 `pymupdf4llm` 优先 + MarkItDown 回退的双策略，大文件（>1MB）走 `asyncio.to_thread`，并内置 SEC 申报粗体标题正则修复与大纲提取。
- `readability.py`：基于 `readabilipy`（可选 Readability.js 子进程）+ `markdownify` 将 HTML 抽取为 `Article`，再拆成 LangChain 兼容的 `{type, text/image_url}` 内容块。
- `messages.py`：对 LangChain `BaseMessage` 或 dict 形 `content` 做多态扁平化为纯文本，保留 `original_user_content` 原始值通道。
- `llm_text.py`：清理模型响应中的 `<think>` 推理块与外层 markdown 代码围栏，统一提取结构化文本。
- `time.py`：集中定义 ISO 8601 UTC 时间写入 (`now_iso`) 与历史 unix 浮点字符串兼容读取 (`coerce_iso`)，作为 Gateway 与嵌入式运行时唯一的时间源。
