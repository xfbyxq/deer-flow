模块以 `types.py` 中的不可变数据类 `Skill` / `SecretRequirement` / `SkillCategory` 为领域核心，围绕其构建以下分层：
- 抽象存储层：`storage/skill_storage.SkillStorage` 是 ABC，定义 `_iter_skill_files`、`read_custom_skill`、`write_custom_skill`、`ainstall_skill_from_archive`、`delete_custom_skill` 等原子操作；模板方法 `load_skills`、`ensure_custom_skill_is_editable`、路径辅助方法在基类中实现，子类仅覆盖介质相关细节。
- 具体存储实现：`LocalSkillStorage` 直接读写本地磁盘；`UserScopedSkillStorage` 通过重写 `get_skills_root_path`/`validate_skill_file_path` 将自定义技能重定向到 `{base}/users/{user_id}/skills/custom/`，实现多租户隔离。
- 单例工厂：`storage/__init__.py` 通过 `get_or_new_skill_storage` 返回进程级只读公共技能存储（反射 `SkillsConfig.use` 解析具体类），并通过带 LRU 淘汰（OrderedDict + 双检锁）的 `get_or_new_user_skill_storage` 缓存 per-user 实例，上限 64。
- 安装与安全：`installer.py` 提供纯业务逻辑的 ZIP 解压流程，拒绝绝对路径/`..`/符号链接/二进制魔数，限制总大小，并在移动进保留目标前调用 `permissions.make_skill_tree_sandbox_readable` 去除写权限；随后异步遍历 SKILL.md 及 `scripts/`、`references/`、`templates/` 下的文本文件，委托 `security_scanner.scan_skill_content` 调用 moderation LLM 做 allow/warn/block 决策。
- 前端交互：`catalog.SkillCatalog` 是不可变的延迟发现目录，支持 `select:` 精确选择、`+required rest` 必需前缀、自由正则匹配，结果限 MAX_RESULTS=5；`describe.py` 基于此生成 `describe_skill` 工具供 LLM 主动查询元数据，避免把全部描述塞入系统提示。
- 策略与校验：`tool_policy.py` 聚合各 Skill 的 `allowed_tools` 声明，配合 `always_allowed_tool_names` 过滤工具集；`validation.py` 约束 frontmatter 字段白名单；`parser.py` 负责 SKILL.md 解析；`slash.py` 暴露 `/skill` 斜杠命令入口。
依赖方向：上层（catalog/describe/installer）→ 抽象接口 → 具体存储实现；安全扫描器与权限模块被 installer 单向依赖，不反向引用高层。
