- 领域模型统一用 `@dataclass(frozen=True)` 表达不可变实体（Skill、SecretRequirement、ScanResult），变更通过替换整个对象完成。
- 存储后端遵循 ABC + 模板方法模式：子类仅实现少量原子抽象方法，通用流程（加载、历史序列化、路径校验）集中在基类中组合。
- 全局单例与 per-user 缓存均采用「双检锁 + 独立 Lock」构造，并在配置变化时通过记录配置对象身份来失效重建。
- 所有外部输入（ZIP 成员名、relative_path、support file path）在进入文件系统前都先经 `resolve()` 再 `relative_to()` 校验，防止目录穿越。
- 异步 I/O 通过 `asyncio.to_thread` 或 `ThreadPoolExecutor` 从事件循环中卸载阻塞操作，避免阻塞协程调度。
