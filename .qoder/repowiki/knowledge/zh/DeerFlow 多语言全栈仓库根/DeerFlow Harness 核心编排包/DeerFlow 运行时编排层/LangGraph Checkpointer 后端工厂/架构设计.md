模块以 provider.py（同步）与 async_provider.py（异步）两条对称路径实现同一抽象：根据 `CheckpointerConfig.type` 选择 `InMemorySaver`、`SqliteSaver`/`AsyncSqliteSaver` 或 `PostgresSaver`/`AsyncPostgresSaver`。
- 同步侧：`get_checkpointer()` 返回进程级单例（带 `threading.Lock` 双重检查），`reset_checkpointer()` 可关闭底层连接；`checkpointer_context()` 提供无缓存的一次性上下文。
- 异步侧：`make_checkpointer()` 是 `asynccontextmanager`，不持有全局状态，优先读取 legacy `app_config.checkpointer`，回退到统一 `database` 配置，再回落到 `InMemorySaver`。
- 依赖方向：本模块只向上依赖 `deerflow.config.*` 与 `deerflow.runtime.store._sqlite_utils`（解析 sqlite 路径、创建父目录），向后直接 import langgraph 的对应 saver 类，避免循环导入。
- 错误信息常量（`SQLITE_INSTALL`、`POSTGRES_INSTALL`、`POSTGRES_CONN_REQUIRED`）定义在 provider.py 并通过相对 import 被 async_provider 引用，保证两处提示一致。
- 所有持久化后端在进入上下文后调用 `saver.setup()` 完成建表，退出时由各自 saver 的上下文协议负责资源回收。
