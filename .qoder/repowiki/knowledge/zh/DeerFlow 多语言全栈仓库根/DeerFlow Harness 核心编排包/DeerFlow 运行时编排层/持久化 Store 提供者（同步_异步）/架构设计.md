模块以 provider.py 和 async_provider.py 分别实现同步与异步两套入口，二者共享 _sqlite_utils.py 中的 SQLite 连接字符串解析与父目录创建逻辑。

- 配置解析：_resolve_store_config 优先读取旧的 checkpointer 段以保持与 Checkpointer 一致，否则回退到统一的 database 段；未找到配置文件时默认使用 memory 后端。
- 后端分发：_sync_store_cm / _async_store 根据 config.type 动态导入 langgraph.store.memory、langgraph.store.sqlite、langgraph.store.postgres 对应实现，并在 with/async with 块中调用 store.setup() 完成建表。
- 同步 API：get_store() 返回线程安全的进程级单例（内部用 threading.Lock + 全局 _store/_store_ctx 缓存），reset_store() 关闭上下文并清空缓存，store_context() 提供一次性上下文管理。
- 异步 API：make_store(app_config=None) 作为 FastAPI lifespan 风格的异步上下文管理器，不持有全局状态，适合每个请求或应用生命周期内复用。
- 依赖方向：本模块只向上依赖 deerflow.config.* 读取配置，向下通过延迟 import 绑定 langgraph.store.* 具体后端，避免在缺少可选包时启动失败。
