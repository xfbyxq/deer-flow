- 对外可变的运行期状态集中在 `RunRecord` dataclass 中，仅通过 `RunManager` 的 async 方法修改，禁止外部直接赋值字段。
- 所有写路径先持锁更新内存再调用 `_persist_*` 落盘，失败时由 finally 分支回滚 `_runs` 与 `_runs_by_thread` 索引，保证内存与持久化的一致性边界。
- 对 SQLite 等易争用后端的短写操作统一走 `_call_store_with_retry` + `PersistenceRetryPolicy`，通过消息片段与 sqlite_errorcode 判定是否可重试。
- 查询类方法（get/list_by_thread）采用“内存优先 + store 回退”的双层查找，并在两次内存访问之间释放锁以避免阻塞。
- 日志输出统一以 `logger.info/warning` 附带 `run_id`/`thread_id` 前缀，便于跨进程追踪同一 run 的生命周期。
