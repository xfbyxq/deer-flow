模块以抽象协议为中心：`base.py` 定义 `StreamBridge` ABC、不可变 `StreamEvent` dataclass 以及 `HEARTBEAT_SENTINEL`/`END_SENTINEL` 两个控制哨兵；具体实现通过工厂 `async_provider.make_stream_bridge` 按配置动态选择。
- `memory.py`：基于 `asyncio.Condition` + 每 run 的列表缓冲，支持 `Last-Event-ID` 重放与过期截断，`supports_cross_process=False`。
- `redis.py`：基于 Redis Streams 的跨进程实现，使用 `XADD/XREAD BLOCK` 持久化回放，带指数退避重试与 TTL 清理，`supports_cross_process=True`；`redis.asyncio` 作为可选依赖懒加载，未安装时抛出明确安装提示。
- `__init__.py` 仅暴露内存实现与公共符号，显式注释说明不导入 redis 以避免对单进程部署引入额外依赖。
依赖方向：`memory` / `redis` → `base`；`async_provider` → `base` + 配置层 (`deerflow.config`)；上层只依赖 `make_stream_bridge` 返回的 `StreamBridge` 接口。
