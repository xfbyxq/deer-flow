本模块作为 DeerFlow 运行时的装配中心，通过 `__init__.py` 把五个子能力聚合为单一公共入口：
- 后端工厂：`checkpointer` 与 `store` 各自提供同步/异步两套工厂（`make_*` + `*_context`），按配置在 memory/sqlite/postgres 间切换，并由 `runs.manager.RunManager` 在创建 Run 时注入到 LangGraph graph。
- 执行编排：`runs.worker` 启动后台任务，持有 `RunJournal`（基于 LangChain callback 收集 llm/tool/run 事件写入 `events.store`）和 `StreamBridge`（内存或 Redis Streams），前者负责 token 累计与进度快照，后者负责 SSE 推送；两者共享 `run_id/thread_id` 标识。
- 数据契约：`goal.py`、`journal.py`、`serialization.py`、`converters.py`、`secret_context.py`、`user_context.py` 等纯函数/上下文载体被 runs/checkpointer/stream_bridge 共同消费，构成跨子模块的共享边界——如 `REDACTED_CONTEXT_KEYS` 由 secret 解析与 tracing 两端共用，`langchain_to_openai_*` 转换器供日志/序列化使用。
- 隔离策略：Redis 相关实现（`stream_bridge.redis`、`checkpointer.async_provider`）以可选 extra 形式延迟导入，避免进程启动即加载 redis 依赖。
