- 每个实体子包采用 model.py + sql.py + __init__.py 三段式布局，__init__.py 只 re-export Row 与 Repository 两类符号。
- Repository 通过构造函数接收 async_sessionmaker[AsyncSession] 而非全局 session，所有写操作以 `async with self._sf() as session:` 包裹并在末尾 commit/refresh。
- 查询结果统一经由 `_row_to_dict` 转换，并把所有 datetime 字段交给 `coerce_iso` 转成 ISO 字符串后再返回给调用方。
- 涉及状态变更的方法接受 `protect_terminal: bool = False` 参数，当目标行已处于终端状态时跳过覆盖，用于处理完成钩子与启动路径的竞态。
- 时间戳字段一律使用 `DateTime(timezone=True)` 并配合 `datetime.now(UTC)` 写入，避免本地时区污染。
