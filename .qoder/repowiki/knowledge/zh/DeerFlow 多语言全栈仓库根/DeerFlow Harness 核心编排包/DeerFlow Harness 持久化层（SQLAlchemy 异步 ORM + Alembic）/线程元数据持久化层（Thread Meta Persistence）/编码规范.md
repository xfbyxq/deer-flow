- 所有写操作方法的 `user_id` 参数统一采用 `str | None | _AutoSentinel = AUTO` 三态签名，并在方法入口调用 `resolve_user_id(user_id, method_name=...)` 解析上下文所有者。
- 更新类方法遵循「先校验所有权再落盘」模式：先 `resolve_user_id` → 读取行 → 比对 `row.user_id` → 不匹配则直接返回（幂等无错）。
- 对外返回的时间字段统一经 `coerce_iso` 处理，确保 SQLite 丢失 tzinfo 时仍输出带时区的 ISO 字符串。
- JSON 列上的动态过滤必须走 `json_match`，捕获 `ValueError`/`TypeError` 后记录警告，若全部被拒绝则抛出 `InvalidMetadataFilterError`。
- 面向外部消费者的构造入口集中在 `__init__.py` 的 `make_thread_store` 工厂，由上层按运行环境注入 `session_factory` 或 `store`，避免调用方直接依赖具体实现。
