模块按职责切分为四个文件，依赖方向单向：`engine.py` → `bootstrap.py` → `migrations/`；`base.py` 被 `bootstrap.py` 和 `migrations/env.py` 共同引用。

- `engine.py`：全局单例 `AsyncEngine` + `async_sessionmaker` 的创建/销毁入口，支持 `memory/sqlite/postgres` 三种后端；对 sqlite 通过连接事件钩子开启 WAL/NORMAL/synchronous/foreign_keys/busy_timeout=30s，并内置 `_auto_create_postgres_db` 在数据库不存在时自动 `CREATE DATABASE`。
- `bootstrap.py`：三分支混合引导器——空库走 `Base.metadata.create_all` + `stamp head`，遗留库回填 `_BASELINE_TABLE_NAMES` 后 `stamp 0001_baseline` + `upgrade head`，已版本化库直接 `upgrade head`；Postgres 用 `pg_advisory_lock(0x0DEE_12F1_0BEE_3682)` 做跨进程互斥，SQLite 用 per-engine `asyncio.Lock` + 30s `busy_timeout` 做进程内串行与跨进程尽力而为。
- `base.py`：自定义 `DeclarativeBase`，基于 `@cache` 的列反射提供通用 `to_dict()` / `__repr__`，避免每个模型重复序列化逻辑。
- `json_compat.py`：实现 `JsonMatch` 自定义 `ColumnElement`，通过 `@compiles` 针对 sqlite (`json_type`/`json_extract`) 与 postgres (`json_typeof`/`->>`) 分别编译类型安全的 JSON 值匹配，键名经正则白名单校验防止 SQL/JSONPath 注入。
- `migrations/`：标准 Alembic 环境，`env.py` 通过 `include_object` 显式排除 LangGraph checkpointer 表，离线模式启用 `render_as_batch=True` 以支持 SQLite ALTER TABLE；`versions/` 下存放增量迁移脚本（baseline、runs token_usage、scheduled_tasks）。
