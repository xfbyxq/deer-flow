- 所有 ORM 模型继承自本模块的 `Base`，统一通过其 `to_dict(exclude=...)` 进行序列化，禁止在模型中手写 `to_dict`。
- 对 JSON 列的过滤一律通过 `json_match(column, key, value)` 构建谓词，键名必须匹配 `[A-Za-z0-9_-]+`，值仅限 None/bool/int(float)/str 且 int 限定在 signed 64-bit 范围。
- Alembic 迁移脚本位于 `migrations/versions/` 下，文件名采用 `NNNN_<slug>.py` 顺序编号，新增列/索引必须写为幂等的增量 revision，不得直接编辑 baseline 或手动 ALTER。
- 跨进程 DDL 操作通过后端特定的锁抽象封装：Postgres 使用 `pg_advisory_lock`，SQLite 使用 per-engine `asyncio.Lock`，并由 `_bootstrap_lock(engine, backend)` 统一分派。
- 异步阻塞调用（如 Alembic 同步命令、`os.makedirs`）统一通过 `asyncio.to_thread` 包装，避免阻塞 FastAPI lifespan 事件循环。
