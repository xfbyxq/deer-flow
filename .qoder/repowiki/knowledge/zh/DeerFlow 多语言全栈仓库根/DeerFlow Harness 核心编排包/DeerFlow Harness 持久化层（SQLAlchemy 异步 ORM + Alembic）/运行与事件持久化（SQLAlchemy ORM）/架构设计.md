模块按职责拆分为两个子目录：
- `run/`：定义 `RunRow`（表 `runs`，主键 `run_id`，含 token 用量、follow_up 等聚合字段）并通过 `RunRepository` 实现 `deerflow.runtime.runs.store.base.RunStore` 接口；每个方法使用 `async_sessionmaker` 构造短生命周期 `AsyncSession`，避免跨长时间任务持有连接。
- `models/`：定义 `RunEventRow`（表 `run_events`，自增主键 + `(thread_id, seq)` 唯一约束），供事件存储层使用。
依赖方向单向向外：本模块仅依赖 `deerflow.persistence.base.Base`、`deerflow.runtime.runs.store.base.RunStore`、`deerflow.runtime.user_context.resolve_user_id` 以及 `deerflow.utils.time.coerce_iso`，不反向依赖上层运行时或 UI 层。`sql.py` 通过 `_row_to_dict` 将内部 JSON 列名（`metadata_json`/`kwargs_json`）映射回接口约定的 `metadata`/`kwargs`，并对 SQLite 丢失时区的问题做兼容处理。
