- 所有写操作都通过 `async with self._sf() as session:` 获取短生命周期会话并在末尾显式 `commit()`，禁止跨调用持有连接。
- 对外暴露的 `user_id` 参数统一以 `AUTO` 哨兵值传入，由 `resolve_user_id(user_id, method_name=...)` 在方法入口处解析并用于行级权限过滤。
- JSON 列写入前一律经 `_safe_json` 递归清洗，优先走 Pydantic `model_dump()` / `dict()`，失败则退化为 `str()`，保证 SQLite JSON 可序列化。
- ORM 模型字段采用 `Mapped[...] = mapped_column(...)` 新式声明，时间戳默认使用 `lambda: datetime.now(UTC)` 而非 `datetime.utcnow`。
- 字符串列长度限制与截断策略集中在静态方法中（如 `_normalize_model_name` 截至 128 字符、消息文本截至 2000 字符），避免散落在业务逻辑里。
