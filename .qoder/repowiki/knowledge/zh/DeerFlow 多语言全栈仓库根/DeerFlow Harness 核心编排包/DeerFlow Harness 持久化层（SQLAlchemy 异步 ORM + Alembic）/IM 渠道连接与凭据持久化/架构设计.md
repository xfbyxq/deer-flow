模块按 `model.py` + `sql.py` 分层：
- `model.py` 定义四个 ORM 表（`channel_connections`、`channel_credentials`、`channel_oauth_states`、`channel_conversations`），全部继承自 `deerflow.persistence.base.Base`，并通过 `UniqueConstraint` 与部分唯一索引在数据库层强制“单活跃所有者”和“外部身份唯一”不变式。
- `sql.py` 暴露 `ChannelConnectionRepository` 作为统一持久化门面，封装所有异步 CRUD；`ChannelCredentialCipher` 基于 `cryptography.fernet.Fernet` 对 access/refresh token 与 extra JSON 做前缀 `fernet:v1:` 的加解密。
- 并发安全通过三层保障：`upsert_connection` 捕获 `IntegrityError` 并重试最多 `_UPSERT_MAX_ATTEMPTS=3` 次以应对部分唯一索引冲突；`create_oauth_state_within_cap` 使用 PostgreSQL `pg_advisory_xact_lock`（SQLite 借 DELETE 写锁隐式串行化）保证 per-(owner, provider) 挂起上限；`consume_oauth_state` 用条件 UPDATE 防止重复消费。
- 依赖方向单向：`sql.py` → `model.py` → `Base`，`__init__.py` 仅重新导出对外 API，不引入额外耦合。
