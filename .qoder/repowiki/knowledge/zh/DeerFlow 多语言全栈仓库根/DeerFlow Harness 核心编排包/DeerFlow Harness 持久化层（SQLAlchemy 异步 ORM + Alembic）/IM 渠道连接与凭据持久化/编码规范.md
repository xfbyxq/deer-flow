- 所有时间字段统一使用 `datetime.now(UTC)` 作为默认值，并在 `_coerce_datetime` 中把 naive datetime 附加 UTC 时区后再返回给调用方。
- 可选字符串标识符（external_account_id、workspace_id、external_topic_id）一律通过 `_normalize_optional_identity` 归一化为空串再落库，避免 NULL 语义歧义。
- JSON 列采用 `_json` 后缀（`scopes_json`、`capabilities_json`、`metadata_json`、`encrypted_extra_json`），对外接口则以无后缀键名（`scopes`、`capabilities`、`metadata`、`extra`）呈现，由 `_connection_to_dict` 完成转换。
- 敏感字段写入前先检查 `_cipher is None` 并抛出 `RuntimeError`，读取侧则捕获 `InvalidToken` / `UnicodeError` / `json.JSONDecodeError` 降级为 None 而非向上抛错。
- 需要跨进程/线程一致性的事务内操作统一包裹在 `async with self.session_factory() as session:` 块中，显式 `commit()` 后不再依赖自动 flush。
