本模块按领域划分子包（run、thread_meta、scheduled_tasks/scheduled_task_runs、channel_connections、feedback、user），每个子包遵循相同的 model.py/sql.py 双文件约定：model.py 声明 SQLAlchemy 映射，sql.py 基于 engine.py 暴露的 `AsyncSession` 实现 CRUD 仓库。
- 共享基础设施位于根目录：`engine.py` 负责引擎创建/销毁与 `AsyncSession` 生命周期；`bootstrap.py` 在应用启动时调用各子包的 `init_db` 完成表结构引导；`base.py` 提供所有模型的基类（如 UUID PK、时间戳）；`json_compat.py` 封装跨方言 JSON 过滤。
- 迁移由 migrations/ 下的 Alembic 配置管理，版本脚本通过 `_helpers.py` 和 `_env_filters.py` 复用通用逻辑。
- thread_meta 是唯一同时包含 SQL 后端与内存后端的子域，通过 base.py 定义的抽象接口向上屏蔽差异，其余子域仅依赖 SQL 路径。
