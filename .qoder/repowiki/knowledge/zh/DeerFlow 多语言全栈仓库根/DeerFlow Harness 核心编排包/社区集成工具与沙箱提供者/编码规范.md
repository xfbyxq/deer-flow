- 所有第三方工具函数均以 `@tool("name", parse_docstring=True)` 装饰，返回值统一为 JSON 字符串，错误路径也返回包含 `error` 字段的 JSON。
- API Key 与工具参数一律通过 `get_app_config().get_tool_config(<tool_name>).model_extra` 读取，并在环境变量中提供默认值（如 `BRAVE_SEARCH_API_KEY`）。
- 沙箱提供者实现 `acquire` / `release` / `destroy` / `get` 四件套，维护 `thread_id→sandbox_id` 映射与 warm pool，并通过 `uses_thread_data_mounts` 标志声明是否具备宿主文件系统直挂能力。
- 配置项支持 `$VAR` 形式的变量展开，由 `_resolve_env_vars` 静态方法统一处理，避免硬编码敏感信息。
- 对外部资源（Docker、e2b VM、文件锁）的访问均包裹 try/except 并以 logger.warning/error 记录失败，保证单条工具调用不崩溃整个进程。
