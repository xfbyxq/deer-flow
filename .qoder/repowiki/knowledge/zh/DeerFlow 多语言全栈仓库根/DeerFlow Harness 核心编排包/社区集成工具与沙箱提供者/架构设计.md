本模块按功能划分为两类并列的子包：
- 工具子包（brave、tavily、ddg_search、searxng、serper、exa、groundroute、infoquest、jina_ai、browserless、crawl4ai、fastcrw、firecrawl、image_search 等），每个子包通过 `@tool(...)` 装饰器暴露 LangChain Tool，统一从 `deerflow.config.get_app_config().get_tool_config()` 读取 API Key 与参数，并以 JSON 字符串返回结果。
- 沙箱提供者子包（`aio_sandbox`、`e2b_sandbox`、`boxlite`），实现框架层 `deerflow.sandbox.sandbox_provider.SandboxProvider` 接口；其中 `aio_sandbox.AioSandboxProvider` 通过抽象 `backend.SandboxBackend`（`LocalContainerBackend` / `RemoteSandboxBackend`）在本地 Docker 与远程 K8s Provisioner 之间切换，并组合 `WarmPoolLifecycleMixin` 实现基于 idle_timeout 和 replicas 的预热池 LRU 淘汰。
- 共享安全与生命周期：`url_safety.py` 提供 SSRF 防护（解析主机名、拒绝私有/回环/保留地址、Google metadata 黑名单），被各 web 工具复用；`warm_pool_lifecycle.py` 提供带后台线程的通用预热池清理逻辑，由 AioSandboxProvider 继承实现 `_active_count_locked` / `_destroy_warm_entry` 钩子。
依赖方向：工具 → config + url_safety；沙箱提供者 → SandboxProvider 抽象 + WarmPoolLifecycleMixin + 具体 backend；无反向依赖。
