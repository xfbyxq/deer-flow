- 对外入口函数一律返回空列表或空 dict 作为“无可用资源”的优雅降级，而非抛出异常（如 `get_mcp_tools` 在缺少依赖或未启用 server 时）。
- 异步 I/O 与文件系统操作（workspace 快照、递归遍历）通过 `asyncio.to_thread` 移出事件循环，避免阻塞主循环。
- 需要跨 event loop 调用的清理路径采用“信号 owner task + 等待其 own loop 上执行”的模式，禁止从不同 loop/task 直接 await 另一个 loop 上的协程。
- 模块级可变状态（工具缓存、session pool 单例）配合 `threading.Lock` 或 `asyncio.Lock` 保护，并提供对应的 reset 函数供测试使用。
