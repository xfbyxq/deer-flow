- 服务端布局中通过 `getServerSideUser()` 返回的 tagged union result.tag 做 switch 分支，并用 `assertNever(result)` 兜底未覆盖类型。
- 需要实时数据的布局/页面显式声明 `export const dynamic = "force-dynamic"`，避免 Next.js 缓存导致用户态失效。
- API 代理统一采用 `buildBackendUrl(pathname)` 拼接 `NEXT_PUBLIC_BACKEND_BASE_URL`，并在转发前删除 host/connection/content-length 头。
- 静态演示模式通过 `env.NEXT_PUBLIC_STATIC_WEBSITE_ONLY === "true"` 条件判断，对写入类操作直接 return 或禁用 UI 元素。
- 动态路由使用 `generateStaticParams` 结合 `isStaticWebsiteOnly()` 与 `DEMO_THREAD_IDS` 在构建期预渲染 demo 线程页面。
