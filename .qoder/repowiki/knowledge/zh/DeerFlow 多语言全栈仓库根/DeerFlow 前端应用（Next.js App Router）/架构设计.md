本模块以 `src/app` 为入口，通过 Next.js App Router 的路由分组 `(auth)`、`workspace`、`[lang]/docs`、`blog` 等把页面层与业务域解耦；所有业务逻辑下沉到 `src/core/<domain>`（agents/threads/memory/sidecar/channels/mcp/skills/tasks/uploads/settings/i18n 等），每个子域统一提供 `api.ts` + `hooks.ts` + `types.ts` 三件套，供 `components/workspace` 和 `components/ai-elements` 消费；`components/ui` 作为跨域原子组件被各页面与业务组件复用；`content/en|zh` 下的 Nextra MDX 文档经 `[lang]/docs` 路由渲染，与业务代码同仓管理。运行时通过 `src/app/api/*` 代理或 Mock 后端，测试套件（`tests/e2e`、`tests/unit`）使用 Playwright 与 rstest 对 core 层 API 与组件进行隔离验证。
