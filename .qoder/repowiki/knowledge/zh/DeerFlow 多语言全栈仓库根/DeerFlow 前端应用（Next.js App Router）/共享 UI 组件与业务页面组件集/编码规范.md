- UI 原子组件统一以 `data-slot="<component>"` 标记根节点，并通过 `data-variant` / `data-size` 暴露 cva 变体值，供 CSS 选择器消费。
- 组件类名一律通过 `cn(...)` 合并，基础样式与变体样式拆分为多段字符串传入 cn，保持可读性。
- 复杂状态域在子目录内创建独立的 `context.tsx`，导出 `*ContextType` 接口、Provider 组件与 `useXxx()` hook，hook 内部对 undefined context 抛错以保证调用契约。
- 子目录通过 `index.ts` barrel 文件集中 re-export，外部仅依赖目录路径而非具体文件名。
- 需要 DOM 或浏览器 API 的组件在文件首行标注 `'use client'`，并在顶层用 `typeof document !== 'undefined'` 包裹副作用初始化代码以兼容 SSR。
