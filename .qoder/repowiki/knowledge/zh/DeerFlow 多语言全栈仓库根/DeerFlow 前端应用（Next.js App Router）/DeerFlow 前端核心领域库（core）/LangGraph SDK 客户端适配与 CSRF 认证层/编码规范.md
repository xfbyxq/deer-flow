- CSRF 防护采用 Double Submit Cookie 模式：状态变更方法统一由 `isStateChangingMethod` + `readCsrfCookie` 注入 `X-CSRF-Token`，禁止直接裸调原生 `fetch`。
- 对第三方 SDK 实例使用 monkey-patch（`client.runs.stream = ... as typeof ...`）注入横切逻辑，而非继承或代理，以保持调用方无需感知。
- 错误分类通过带 `needles` 子串的 `isRunConflictError` 匹配 409 响应体片段，再派生出 `isInactiveRunStreamError` / `isRunNotCancellableError` 等语义化谓词。
- 可选参数以 `isMock?: boolean` 形式传入工厂函数，内部用 `Map<string, LangGraphClient>` 缓存单例，键为 `mock` / `default`。
- 不可变集合（`ReadonlySet`、`new Set([...])`）用于声明式白名单（HTTP 方法、流模式），配合 `has()` 做 O(1) 判定。
