模块围绕 `@langchain/langgraph-sdk/client` 的 `LangGraphClient` 做一层薄适配，按职责拆分为：
- `api-client.ts`（入口）：通过 `getAPIClient(isMock?)` 单例工厂返回客户端；在 `isStaticWebsiteOnly()` 时走 `createStaticClient()` 用 `../threads/static-demo` 的数据填充 threads/runs 方法，否则基于 `getLangGraphBaseURL` 构造真实客户端，并通过 monkey-patch `runs.stream` / `runs.joinStream` / `runs.cancel` 注入重连短路、409 冲突识别与 `clearReconnectRun` 清理逻辑。
- `fetcher.ts`：提供全局 `fetch` 包装器，对 POST/PUT/DELETE/PATCH 自动从 `csrf_token` Cookie 读取并注入 `X-CSRF-Token` 头（Double Submit Cookie），并在 401 时跳转登录；同时导出 `readCsrfCookie` / `isStateChangingMethod` 供 `api-client.ts` 复用。
- `stream-mode.ts`：维护 `SUPPORTED_RUN_STREAM_MODES` 白名单，`sanitizeRunStreamOptions` 在每次调用 `runs.stream/joinStream` 前过滤掉不支持的模式并只告警一次。
- `errors.ts`：集中解析 FastAPI `{ detail }` 错误信封，供上层 domain API 模块复用。
- `feedback.ts`：基于 `fetcher.fetch` 实现的反馈 PUT/DELETE 业务接口。
- `index.ts`：仅 re-export `api-client`，作为对外唯一入口。
依赖方向单向：`api-client → fetcher/stream-mode/errors`，`feedback → fetcher`，无循环依赖。
