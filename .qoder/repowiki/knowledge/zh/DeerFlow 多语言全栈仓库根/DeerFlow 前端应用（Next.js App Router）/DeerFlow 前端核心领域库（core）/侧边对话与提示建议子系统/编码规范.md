- 对外暴露的 API 同时接受单个对象或对象数组参数，并在内部通过 `normalizeSidecarContexts` 归一化为数组，再保证各字段数组与 contexts 保持 1:1 并行关系。
- 所有面向后端的 JSON 字段名采用 snake_case（如 `parent_thread_id`、`message_id`、`referenced_message_contexts`），而前端内部类型一律使用 camelCase（如 `parentThreadId`、`messageId`），转换集中在 `build*` / `read*` 函数中完成。
- 构建结构化文本（prompt、XML 块）时使用 `filter((line): line is string => line !== null)` 模式过滤掉空行，再用 `join('\n')` 拼接，避免硬编码换行逻辑。
- 对来自外部不可信源的字符串（XML 属性、用户内容）在进入 XML 前显式调用 `escapeXmlAttribute` 进行 `& < > "` 转义，防止注入。
- 并发安全通过模块级 `Map<string, Promise<T>>` 记录 in-flight 请求，key 为业务唯一标识（如 `parentThreadId`），settled 后清理条目，从而合并重复调用。
