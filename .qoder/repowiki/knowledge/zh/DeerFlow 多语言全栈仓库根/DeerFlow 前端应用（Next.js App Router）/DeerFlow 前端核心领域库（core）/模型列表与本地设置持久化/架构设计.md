模块由两个并列子包组成：
- `models/`：纯数据层。`types.ts` 定义 `Model`、`TokenUsageSettings`、`ModelsResponse`；`api.ts` 通过 `fetch(getBackendBaseURL()/api/models)` 拉取数据，并在 `isStaticWebsiteOnly()` 时回退到空静态响应；`hooks.ts` 用 `@tanstack/react-query` 暴露 `useModels`，将原始响应解构为 `{ models, tokenUsageEnabled, isLoading, error }`。
- `settings/`：客户端状态层，采用 store + hooks 分离。`local.ts` 定义 `LocalSettings` 结构（notification / tokenUsage / context）及 `DEFAULT_LOCAL_SETTINGS`，负责 `localStorage` 的序列化、合并与按 `deerflow.thread-model.<threadId>` 前缀存储线程模型覆盖；`store.ts` 维护内存中的 base settings 快照与 thread model 缓存，通过 `Set<Listener>` 实现发布-订阅，并监听 `window.storage` 事件以跨标签页同步；`hooks.ts` 使用 `useSyncExternalStore` 暴露 `useLocalSettings` 和 `useThreadSettings`，后者在基础设置之上叠加线程模型覆盖。
依赖方向：`hooks.ts` → `store.ts` → `local.ts`；`models/hooks.ts` → `models/api.ts` → `../config` / `../static-mode`；两层互不依赖，仅通过各自 hooks 被上层 UI 消费。
