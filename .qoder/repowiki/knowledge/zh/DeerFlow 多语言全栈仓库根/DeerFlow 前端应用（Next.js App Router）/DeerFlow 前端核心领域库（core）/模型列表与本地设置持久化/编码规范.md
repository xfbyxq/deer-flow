- 对外暴露的 React hook 统一返回 `[state, setter]` 元组形式，setter 签名固定为 `(key, partialValue) => void` 的局部合并更新。
- 所有涉及 DOM 的操作（`localStorage`、`window.addEventListener`、`typeof window`）均先通过 `isBrowser()` / `typeof window === 'undefined'` 守卫，保证 SSR 安全。
- 设置项变更走 `mergeSettingsSection` / `mergeLocalSettings` 对每个 section 做浅合并，避免覆盖未传入字段。
- 跨标签页同步通过 `window.addEventListener('storage', ...)` 监听，并以 `LOCAL_SETTINGS_KEY` 或 `THREAD_MODEL_KEY_PREFIX` 前缀匹配区分全局设置与线程模型键。
