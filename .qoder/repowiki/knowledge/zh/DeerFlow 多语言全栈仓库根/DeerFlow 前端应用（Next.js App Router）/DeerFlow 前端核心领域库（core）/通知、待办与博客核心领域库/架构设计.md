本模块由三个互不依赖的子包组成，均位于 `frontend/src/core/` 下，作为上层页面/组件的共享领域层：
- `notification/hooks.ts`：封装浏览器 Notification API 的 React Hook，通过 `useLocalSettings()` 读取用户开关，并内置 1s 节流与权限状态同步；仅暴露 `{ permission, isSupported, requestPermission, showNotification }`。
- `todos/types.ts` + `index.ts`：纯类型声明包，仅导出 `Todo` 接口（content/status），`index.ts` 统一 re-export，供其他 core 或页面引用。
- `blog/index.ts`：基于 `nextra/page-map` 的静态数据层，按 `BLOG_LANGS = ['zh','en']` 并行拉取多语言 `/posts` 树，经 `collectLocalizedBlogPosts` → `mergePostsBySlug` 合并为单篇 `BlogPost`（含 `languages[]` 与并集 tags），并通过 `cache()` 缓存 `getAllPosts`；`getBlogIndexData` 在此基础上生成 tag 分组、最近文章与动态 `PageMapItem` 树，同时提供 `getBlogRoute`、`normalizeTagSlug`、`formatTagName`、`getPreferredBlogLang` 等工具函数。依赖方向单向：`blog` 仅依赖 `@/core/i18n/locale`，`notification` 仅依赖 `../settings`，`todos` 无运行时依赖。
