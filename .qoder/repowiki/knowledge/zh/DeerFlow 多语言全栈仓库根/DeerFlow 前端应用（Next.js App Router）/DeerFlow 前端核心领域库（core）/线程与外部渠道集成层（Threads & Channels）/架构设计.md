模块按领域拆分为两个并列子目录，各自遵循「types → api → hooks」分层：
- `threads/`：以 `hooks.ts` 为核心，通过 `@langchain/langgraph-sdk/react` 的 `useStream` 订阅 `lead_agent` 助手，将后端返回的 `AgentThreadState` 与本地 optimistic 消息、归档历史合并；`api.ts` 仅暴露 `fetchThreadTokenUsage`、`branchThreadFromTurn` 两个 HTTP 调用，错误统一走 `readThreadAPIError`；`thread-search-query.ts` 把 LangGraph `threads.search` 包装成 React Query 的 `queryKey: ["threads","search",params]` 查询并提供分页循环；`token-usage.ts`、`utils.ts`、`export.ts`、`static-demo.ts` 是纯函数工具。
- `channels/`：`types.ts` 定义 ChannelProvider / ChannelConnection 等 DTO；`api.ts` 集中访问 `/api/channels/*` 并通过 `throwGatewayApiError` 抛错；`connect-poll.ts` 实现无状态的 `startConnectionPoll`（2s 间隔 + 过期截止），由 `hooks.ts` 中的 `useConnectChannelProvider` 在 mutation onSuccess 时启动并在组件卸载时 cancel；`provider-state.ts` 提供 `providerCanConnect` 等派生布尔值供 UI 使用。
依赖方向：hooks 只读 types 与 api，不反向依赖；poll 与 provider-state 是纯逻辑，可被任意组件复用。
