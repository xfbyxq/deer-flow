- 每个领域子目录都采用 types.ts 声明 DTO、api.ts 封装 fetch 调用、hooks.ts 组合 useQuery/useMutation 暴露给 UI 的分层约定。
- HTTP 响应失败一律通过 `throwGatewayApiError` 或自定义 `readXxxAPIError` 解析 JSON detail 字段后抛出，避免直接向上冒泡原始 Response。
- React Query 的 queryKey 使用具名字符串常量（如 `channelProviderQueryKey`、`INFINITE_THREADS_QUERY_KEY_PREFIX`）并以 const 数组形式导出，mutation onSuccess 中显式 invalidate 相关 key。
- 对外部异步副作用（连接轮询、停止线程后的延迟刷新）通过 ref + useEffect 清理模式管理生命周期，确保组件卸载时 cancel 定时器。
