- 每个子域以 api.ts 定义 REST 调用、types.ts 声明 TS 类型、hooks.ts 封装 React Query hook、index.ts 聚合导出的固定文件结构
- 所有后端请求统一经 api/api-client.ts 的 LangGraphClient 实例发起，禁止在子域内直接使用原生 fetch 访问后端
- React Query hook 命名采用 useXxx 形式并返回包含 data/error/isLoading 的标准查询结果对象
- 特性开关与用户偏好通过 settings/local.ts 的 localStorage 读写，而非散落在组件内部
