- API 函数统一通过 `fetch(...)` 调用，失败时读取 JSON `detail` 字段并以 `throw new Error(detail)` 抛出，错误信息带业务语义前缀（如 "Upload failed"）。
- React Query hook 的 `queryKey` 采用 `["uploads", <action>, threadId]` 三段式命名，mutation 成功回调中通过 `invalidateQueries({ queryKey: ["uploads", "list", threadId] })` 刷新列表缓存。
- 对外暴露的接口类型集中在同名文件中（如 `UploadedFileInfo`、`UploadLimits`、`TokenUsage`），并通过 `index.ts` 或同级导出供上层消费，避免跨目录循环引用。
- 对不可信的后端 payload 一律先做运行时规范化（`asRecord` / `readString` / `isTokenUsageAttributionKind` 守卫），再映射到强类型联合，而非直接断言。
