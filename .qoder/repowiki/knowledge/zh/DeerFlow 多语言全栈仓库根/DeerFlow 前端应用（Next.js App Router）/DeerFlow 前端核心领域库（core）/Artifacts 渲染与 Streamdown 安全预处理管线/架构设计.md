模块由三个并列子包构成，职责分层清晰：
- `artifacts/`：面向“文件型 artifact”的生命周期层。`loader.ts` 通过 `urlOfArtifact` 构造后端 `/api/threads/:id/artifacts/...` 或 mock/demo URL 并 fetch；`hooks.ts` 用 react-query 缓存 5 分钟，并对以 `write-file:` 开头的虚拟路径走 `buildWriteFileDraftContent` 从线程消息中重建草稿；`preview.ts` 负责 write_file 工具调用结果解析、HTML 预览时注入 `<base>` 与滚动恢复脚本；`utils.ts` 集中处理静态站点/后端 URL 拼接。
- `streamdown/`：Markdown → HTML 的安全渲染层。`preprocess.ts` 在 marked/streamdown 之前对输入做三件事：`capBlockquoteNesting`/`capListNesting` 限制嵌套深度防止浏览器栈溢出；`normalizeLatexMathDelimiters` + `compactDisplayMathBlocks` 把 LLM 输出的 `\(...\)`/`\[...\]` 转成 remark-math 识别的 `$`/`$$` 并把多行 display math 压平为一行；`mermaid.ts` 将带标签的 `-.-.->` 箭头规范化为 Mermaid 原生语法。`plugins.ts` 组合 remark-gfm、remark-math、rehype-raw、rehype-katex，并提供 `reasoningPlugins`（去掉 rehypeRaw 以防幻觉 HTML）。`safe-children.ts` 暴露 `useSafeStreamdownChildren` / `useSafeStreamdownMarkdown` 两个 Hook，把上述预处理串成 useMemo 包裹的管道；`components.tsx` 再把这些 Hook 套到上层 `ClipboardSafeStreamdown`、`MessageResponse`、`ReasoningContent` 之上，形成对外安全的 React 组件。
- `rehype/`：独立的 HAST 处理器 `rehypeSplitWordsIntoSpans`，利用 `Intl.Segmenter("zh")` 把英文单词切进 `<span class="animate-fade-in">` 实现逐词动画，CJK 文本跳过分词；同时导出 `useRehypeSplitWordsIntoSpans` Hook 供 plugins 按需启用。
依赖方向：`streamdown` 依赖 `rehype`；`artifacts` 不依赖 `streamdown`，仅消费 `@/components/ai-elements/*` 和 `../config`、`../static-mode`、`../threads`。
