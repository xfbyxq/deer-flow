- 所有可能触发浏览器栈溢出的 Markdown 结构（blockquote、list）都在进入 marked/streamdown 之前用正则快速探测加行级改写进行裁剪，而非交给解析器处理。
- 对 LLM 输出不可信内容的处理统一采用先字符串预处理、再交给第三方解析器的两段式模式（如 LaTeX 分隔符转换、Mermaid 箭头归一化、嵌套深度裁剪）。
- React 侧的安全封装一律通过 useMemo 包裹纯函数（getSafeStreamdownMarkdown、getSafeStreamdownChildren），并在外层组件中以同名 use* Hook 形式暴露。
- 插件集合以对象常量（streamdownPlugins、reasoningPlugins、streamdownPluginsWithoutRawHtml）导出，并通过过滤/派生复用，避免重复声明 remark/rehype 列表。
