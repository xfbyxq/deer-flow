本模块由三个并列的子目录组成，各自聚焦一类领域能力，彼此无相互依赖：
- `utils/`：纯函数集合，按功能拆分为 `datetime.ts`（基于 date-fns + i18n cookie 的相对时间格式化）、`files.tsx`（扩展名→语言/图标映射及浏览器预览判断，导出 React 组件片段）、`json.ts`（基于 best-effort-json-parser 的容错解析）、`markdown.ts`（提取首行 H1 标题）、`uuid.ts`（对 uuid v4 的单出口重导出）。
- `tools/utils.ts`：面向 LangChain/LangGraph 消息的工具调用解释器，将 ToolCall 名称映射到 i18n 文案，依赖 `../messages/utils.hasToolCalls` 做类型守卫。
- `citations/sources.ts`：从 Markdown 中抽取 `[citation:…](url)` 引用源，通过正则匹配并借助 `maskCode` 屏蔽代码块/行内代码以保留索引对齐，输出带 count/occurrences 聚合的 `CitationSource[]`。

所有子模块均为无副作用的纯函数/常量导出，不持有状态；对外仅暴露命名导出，被上层 UI 或业务逻辑按需 import。
