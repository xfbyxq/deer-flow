- API 函数统一通过 `../api/fetcher` 发起请求并以 `${getBackendBaseURL()}/api/...` 拼接路径，错误响应经统一的 `readMemoryResponse` 或内联 `response.ok` 检查后抛出带语义信息的 Error。
- React Query mutation 在 `onSuccess` 中通过 `queryClient.setQueryData(["memory"], data)` 直接写回 queryKey 对应的缓存，不依赖 refetch。
- 子任务状态更新采用“纯函数 + ref”模式：`computeNextSubtask` 是纯状态机，hook 通过 `tasksRef.current` 读取最新 state 再调用 `setTasks(prev => ...)`，避免异步回补覆盖 SSE 增量。
- 子任务步骤以 `message_index` 为唯一键进行去重合并，`mergeSteps` 保证 live SSE 与分页 backfill 构建同一时间线。
- 结构化后端协议通过常量键名（`SUBAGENT_STATUS_KEY` 等）集中声明，并在 `STRUCTURED_SUBAGENT_KEYS` 白名单中校验，未知字段默认退回 `in_progress` 而非静默失败。
