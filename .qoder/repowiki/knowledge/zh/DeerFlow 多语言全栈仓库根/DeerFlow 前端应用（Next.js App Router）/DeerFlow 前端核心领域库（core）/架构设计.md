本目录是 Next.js 应用的前端核心层，按后端资源/能力垂直切分子域（agents/mcp/skills、threads/channels、memory/tasks、artifacts/streamdown、auth/workspace-changes、messages/uploads、models/settings、suggestions/sidecar、i18n/config、scheduled-tasks、notification/todos/blog），每个子域遵循同一契约：api.ts 调用 api-client.ts 中的 LangGraphClient 适配层（注入 CSRF、流模式白名单、静态站点 Mock），types.ts 定义 TS 类型，hooks.ts 基于 @tanstack/react-query 提供状态管理 Hook，index.ts 作为 barrel 导出。

跨子域共享的横向能力集中在 core_api_client（fetcher + stream-mode）、shared_utils（datetime/files/json/markdown/uuid）、i18n_config（Cookie 驱动的双语与运行时配置）以及 auth（SSR/客户端双端认证上下文）。上层 UI 组件仅依赖各子域的 index.ts 聚合导出，不直接感知底层 LangGraph SDK 或 fetcher 实现。
