- SSR 鉴权结果使用 tagged union（`AuthResult`）并通过 `assertNever` 强制穷尽分支，禁止 try/catch 吞错。
- 所有后端响应在落盘前经 zod schema 校验（如 `userSchema.safeParse`），失败路径统一映射为 `gateway_unavailable` 或具体错误码。
- React 钩子以 `useXxx` 命名并在未包裹 Provider 时抛出明确错误（`useAuth`），需要鉴权的页面组合 `useRequireAuth` 进行路由跳转。
- workspace-changes 的 UI 辅助函数（`getChangedFileCount`、`getWorkspaceChangeLineClass`、`sortWorkspaceChanges`）保持纯函数、无副作用，便于测试与复用。
- 对外 API 函数接受具名对象参数并使用可选默认值（如 `includeFiles = true`），配合 `satisfies RequestInit` 保证请求选项类型安全。
