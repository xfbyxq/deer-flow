- 语言常量集中定义于 `locale.ts`，并通过 `as const` 数组派生 `Locale` 联合类型，新增语言只需在此处追加一项。
- 所有可本地化的字符串都受 `locales/types.ts` 中 `Translations` 接口约束，每个语言文件必须完整实现该结构，缺失字段会在编译时报错。
- 客户端与服务端对 cookie 的访问严格分离：客户端用 `document.cookie`，服务端通过 `import('next/headers').cookies()` 动态导入，避免在顶层引入 Next.js 运行时导致打包污染。
- 语言切换后总是双向持久化——既更新 React state，也写回 `locale` cookie，确保刷新或跨路由后保持一致。
- 配置函数统一采用 `get*BaseURL` 命名并以 `typeof window !== "undefined"` 分支处理 SSR 回退值，保持同一段代码可在客户端与服务端执行。
