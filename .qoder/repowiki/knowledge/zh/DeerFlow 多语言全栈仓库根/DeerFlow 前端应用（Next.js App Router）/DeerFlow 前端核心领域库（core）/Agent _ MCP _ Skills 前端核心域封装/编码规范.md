- 每个资源子目录固定拆分为 `api.ts` + `hooks.ts` + `types.ts`（或 `type.ts`）+ `index.ts`，并通过 index 做 barrel re-export。
- API 层对非 2xx 响应统一抛出带 `status` 字段的领域错误类，并提供 `isAdminRequired` getter 判断 403，以便 UI 层显示管理员提示。
- Hook 层通过 `queryKey` 字符串数组（如 `['agents']`、`['mcpConfig']`、`['skills']`）标识缓存键，并在 mutation 的 `onSuccess` 中用 `invalidateQueries` 使对应 key 失效。
- 所有网络请求均通过 `getBackendBaseURL()` 拼接路径，禁止在业务代码中硬编码绝对 URL。
- 读取后端 JSON 响应时使用 `(await res.json().catch(() => ({}))) as { detail?: string }` 模式安全解析可选的 `detail` 字段，再回退到 `res.statusText`。
