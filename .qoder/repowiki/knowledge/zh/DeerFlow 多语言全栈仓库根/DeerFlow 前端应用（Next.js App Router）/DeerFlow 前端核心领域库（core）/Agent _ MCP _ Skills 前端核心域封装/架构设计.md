模块按资源划分为三个并列子目录 `agents/`、`mcp/`、`skills/`，每个子目录遵循相同的分层约定：
- `api.ts`：基于 `@/core/api/fetcher` 与 `getBackendBaseURL()` 发起 HTTP 请求，将后端 `/api/agents`、`/api/mcp/config`、`/api/skills` 等 REST 端点包装为具名 async 函数，并对非 2xx 响应统一抛出领域错误类（`AgentsApiDisabledError`、`AgentNameCheckError`、`MCPConfigRequestError`、`SkillRequestError`），其中后三者暴露 `isAdminRequired` getter 以区分 403 权限错误。
- `hooks.ts`：使用 `@tanstack/react-query` 的 `useQuery`/`useMutation` 包裹 api 函数，通过 `queryKey` 命名空间隔离缓存，并在 mutation 成功后调用 `queryClient.invalidateQueries` 触发失效刷新；`agents/hooks.ts` 额外提供 `useAgentsApiEnabled` 配合 `feature-cache.ts` 实现 `/api/features` 的 fail-open + localStorage 粘性策略，避免后端宕机时引发 403 风暴。
- `types.ts`（或 `type.ts`）：声明前后端共享的 TS 接口，如 `Agent`、`CreateAgentRequest`、`UpdateAgentRequest`、`MCPServerConfig`、`Skill` 等。
- `index.ts`：仅做 barrel re-export，作为上层消费入口。
依赖方向单向向下：hooks → api → fetcher/config，feature-cache 仅被 agents hooks 使用，不反向依赖 api。
