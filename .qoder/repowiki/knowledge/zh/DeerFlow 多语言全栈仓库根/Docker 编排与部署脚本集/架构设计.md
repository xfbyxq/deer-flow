本模块按职责分为三个并列子域，彼此无运行时依赖：
- `docker/`：生产与开发环境编排。`docker-compose.yaml` 定义 redis/nginx/frontend/gateway/provisioner 五服务拓扑；`docker-compose.dood.yaml` 和 `docker-compose.cli-auth.yaml` 作为可选 overlay，仅在检测到 AioSandboxProvider（DooD）或启用 Claude/Codex CLI 认证时才由 `scripts/deploy.sh` 追加加载，默认不挂载宿主机 Docker socket 以遵循最小权限原则。
- `docker/provisioner/`：独立的 FastAPI 服务（`app.py`），通过 `kubernetes` Python SDK 在宿主 K8s 集群中按需创建/销毁每线程 Pod + NodePort Service，并通过 `/health` 暴露健康检查，供 Gateway 远程调用。
- `scripts/`：围绕容器的运维与引导脚本集合。`deploy.sh` 是统一入口，解析 config.yaml 自动选择 local/aio/provisioner 三种 sandbox 模式并拼装 compose 命令；`dev-entrypoint.sh` 负责 dev 镜像内 uv extras 校验、依赖自愈合与 uvicorn 热重载；`setup_wizard.py` 驱动 `wizard/` 子包完成 LLM/搜索/执行/通道四步交互式配置生成；其余脚本为辅助工具（端口等待、清理、支持包导出、静态分析检测等）。
