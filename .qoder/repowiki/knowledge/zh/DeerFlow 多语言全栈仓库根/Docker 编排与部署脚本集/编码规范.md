- Compose 服务通过环境变量注入所有可配置项，并在 `extra_hosts` 中显式添加 `host.docker.internal:host-gateway` 以便容器访问宿主机资源。
- 敏感密钥（如 BETTER_AUTH_SECRET、DEER_FLOW_INTERNAL_AUTH_TOKEN）优先从 `$DEER_FLOW_HOME` 下持久文件读取，不存在时自动生成并写入，保证跨重启会话一致。
- 可选能力通过独立 YAML overlay 文件（`docker-compose.dood.yaml`、`docker-compose.cli-auth.yaml`）实现，主 compose 文件不包含任何安全敏感挂载，由部署脚本按需 `-f` 追加。
- Provisioner 对 Kubernetes 资源的命名采用固定前缀（`_pod_name`/`_svc_name` 返回 `sandbox-{id}` / `sandbox-{id}-svc`），并通过 label selector 进行查询与清理。
- Setup Wizard 的 provider 定义集中在 `wizard/providers.py` 的 dataclass 列表（`LLM_PROVIDERS`、`SEARCH_PROVIDERS`、`WEB_FETCH_PROVIDERS`），步骤脚本仅消费这些元数据而不硬编码业务逻辑。
