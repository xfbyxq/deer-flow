## 简介
本文件面向“技能管理”能力，系统性阐述技能的安装、更新、卸载与清理、权限与安全扫描、依赖管理与冲突解决、开发者调试与测试方法，以及技能包目录结构与配置文件说明。文档同时提供常用技能的使用示例与最佳实践，帮助使用者与开发者高效掌握技能全生命周期管理。

## 核心组件
- 网关路由：对外暴露技能管理的 HTTP 接口，负责参数校验、鉴权与调用服务层。
- 管理器：协调安装、卸载、更新、列表查询、状态查看等核心流程。
- 安装器：实现从远程仓库（技能市场）拉取与本地包部署的完整流程。
- 加载器：发现并加载已安装的技能元数据与资源。
- 解析器：解析技能清单与描述文件，生成结构化元数据。
- 校验器：对技能包结构、字段约束进行合法性检查。
- 安全扫描：对脚本、依赖、网络访问等进行风险检测。
- 类型定义：统一技能模型、枚举与错误码。
- 配置：集中管理技能路径、仓库源、扫描策略等。
- 工具：为 Agent 提供可执行的操作入口（如安装、卸载、更新）。

## 详细组件分析

### 技能安装流程（从技能市场安装与本地包部署）
- 远程安装（技能市场）
  - 通过网关路由接收安装请求，管理器调用安装器。
  - 安装器根据配置中的仓库源下载技能包，执行校验与安全扫描后，由加载器注册并刷新索引。
- 本地包部署
  - 支持将本地打包好的技能目录或归档直接部署至指定路径，同样经过校验与扫描后注册。

```mermaid
flowchart TD
Start(["开始"]) --> ParseReq["解析安装请求"]
ParseReq --> Source{"来源类型"}
Source --> |远程仓库| Fetch["拉取技能包"]
Source --> |本地包| Copy["复制/解压到目标目录"]
Fetch --> Validate["校验结构/字段"]
Copy --> Validate
Validate --> Scan["安全扫描"]
Scan --> Register["注册并刷新索引"]
Register --> End(["结束"])
```

### 技能更新机制（版本检查与自动更新）
- 版本检查
  - 管理器在更新流程中对比本地版本与仓库最新版本，决定是否升级。
- 自动更新
  - 结合定时任务或触发式钩子，按策略批量检查并执行更新。
- 回滚与一致性
  - 更新前备份当前版本，失败时回滚；更新完成后刷新索引，确保加载一致。

```mermaid
sequenceDiagram

participant Manager as "管理器"
participant Installer as "安装器"

Admin->>Router : "触发更新检查"
Router->>Manager : "执行更新检查"
Manager->>Installer : "比较本地与远程版本"
Installer-->>Manager : "是否需要更新"
alt 需要更新
Manager->>Installer : "执行更新"
Installer->>Loader : "刷新索引"
Loader-->>Manager : "完成"
else 无需更新
Manager-->>Admin : "已是最新"
end
```

### 技能卸载与清理操作
- 卸载流程
  - 管理器调用加载器移除技能元数据与索引项，并清理关联资源（脚本、模板、缓存等）。
- 幂等性与健壮性
  - 重复卸载应返回成功或提示不存在；异常时记录日志并保留最小可用状态。

```mermaid
flowchart TD
Start(["开始"]) --> Find["定位技能实例"]
Find --> Exists{"是否存在"}
Exists --> |否| ReturnOK["返回成功/提示不存在"]
Exists --> |是| RemoveMeta["移除元数据与索引"]
RemoveMeta --> Cleanup["清理脚本/模板/缓存"]
Cleanup --> Refresh["刷新索引"]
Refresh --> End(["结束"])
```

  - 通过类型定义与解析器读取技能依赖清单（脚本、库、外部服务）。

### 技能包目录结构与配置文件说明
- 典型目录
  - SKILL.md：技能描述与使用说明。
  - scripts/：可执行脚本（如数据分析、可视化生成等）。
  - templates/：模板文件（用于报告或内容生成）。
  - references/：参考文档与规范。
