## 简介
DeerFlow 是一个面向 AI 代理执行的基础设施与工具平台，定位为“全栈应用框架”。它通过统一的网关 API、可编排的超级代理、多模式执行环境（本地/沙箱/容器）、可扩展的技能生态、长期记忆系统与多渠道集成能力，帮助开发者快速构建并交付具备复杂任务编排能力的智能体应用。

核心价值主张：
- 超级代理编排：以 LangGraph 为内核，提供可视化与可编程的 Agent 工作流编排能力。
- 多模式执行环境：支持本地、沙箱与容器化执行，兼顾安全隔离与灵活部署。
- 技能生态系统：标准化 SKILL 规范与安装器，便于社区共享与复用。
- 长期记忆系统：会话级与跨会话的记忆存储与检索，支撑持续对话与知识沉淀。
- 多渠道集成：统一接入 Discord、Slack、飞书、微信、企业微信、Telegram 等渠道。
- 全栈一体化：后端 FastAPI + LangGraph，前端 Next.js + React，开箱即用。

适用场景与目标用户：
- 需要构建复杂任务编排的智能体产品团队
- 希望将 LLM 能力工程化落地的研发与数据科学团队
- 需要多渠道发布与运营的智能客服、研究助手、内容生产流水线等

快速开始与在线演示：
- 快速开始：参见仓库根目录文档与脚本向导
- 在线演示：参见前端 README 中的演示入口说明

## 项目结构
DeerFlow 采用前后端分离的全栈结构：
- 后端 backend：基于 Python FastAPI 与 LangGraph，提供网关路由、Agent 编排、技能管理、记忆、上传、MCP 客户端、运行时桥接等能力。
- 前端 frontend：基于 Next.js + React，提供工作区、聊天、模型选择、设置、文档与博客等界面。
- docker：提供开发/生产编排与 Nginx 反向代理配置。
- scripts：包含初始化向导、部署脚本、诊断工具等。
- skills/public：官方公开技能集合，遵循 SKILL 规范。

## 核心组件
- 网关与路由层：统一暴露 REST/SSE 接口，承载线程、运行、工件、记忆、技能、模型、上传、MCP、渠道、建议与兼容助手等能力。
- 超级代理编排：基于 LangGraph 的图状态机，负责节点调度、中间件链、子代理与工具调用。
- 技能生态：SKILL 定义、解析、校验、安装与生命周期管理，支持模板与脚本。
- 执行环境：本地、沙箱与容器化执行，提供安全边界与资源隔离。
- 记忆系统：会话上下文、长期记忆与检索，支持上传过滤与摘要。
- 渠道集成：消息总线与适配器，统一处理多平台消息收发与事件。
- 流式桥接：SSE 流式输出，保障实时交互体验。
- 模型工厂：多模型提供者抽象与凭据加载，屏蔽底层差异。

## 性能考量
- 流式输出：通过 SSE 减少首字节延迟，提升交互体验。
- 并发与异步：网关与渠道回调采用异步处理，提高吞吐。
- 资源隔离：沙箱/容器化执行避免相互干扰，增强稳定性。
- 缓存与索引：对频繁访问的记忆与工件进行缓存优化。
- 限流与降级：对上游模型与工具调用实施限流与容错策略。

## 故障排查指南
- 常见问题定位：
  - 网关路由异常：检查路由注册与依赖注入
  - 代理执行失败：查看 LangGraph 日志与中间件链
  - 渠道回调丢失：核对渠道签名与回调地址
  - 上传失败：确认文件大小、类型与安全扫描结果
